Click the screen to type; RT-11 asks the date and the time at boot, Enter skips both. The keyboard follows the MS7004: the host's letters, digits and symbols make the characters on their caps (РУС mode: positional ЙЦУКЕН); arrows, the numeric keypad, F1–F13; Home/Ins/Del/End/PgUp/PgDn are the editing keys; Left Alt = Compose, Right Alt = РУС/ЛАТ. ⛶ (or F11) puts the picture alone on the whole screen, Esc brings the page back; on a touch device ⌨ raises the system's keyboard (letters, digits, Enter, Backspace - Cyrillic letters switch the machine to РУС). "Joystick: on" makes the arrows and Space the joystick on the MS7007 port (SABOT2 on omega-games: J KEMPSTON), and on a touch screen a stick under a finger on the left of the picture and fire on the right. The drives A, B and HD mount like the desktop emulator's: a 400 KB image is one side, an 800 KB one takes both sides of its drive, the HD takes an image of any size (your own, or a new blank one - INIT HD: in the guest). "Files" replaces the screen with two panes of the mounted disks' RT-11 directories (a floppy side or the HD each, the unused areas shown) and the ten keys below, as in Midnight Commander (Insert or Shift with the arrows marks files - yellow - and F2 / F5 / F6 / F8 take the marked ones; + and - ask for a pattern of the OS to mark or unmark by - * any string, % one character, an omitted part is *, so *.MAC, TEST, A%B.*, several with commas - the marks adding up, and * inverts them; the disks are named as the system names them, DZ0: .. DZ3: and HD0:, and F5 on one file or F6 RenMove take a DZn:NAME - a copy to the same disk under another name, a rename, or a move to another disk): F1 Upload a file of yours (a 6.3 name of A-Z, 0-9 and $), F2 Download to your computer, F3 View, F4 Edit, F5 Copy to the other pane, F6 Rename, F7 Init the pane's volume, F8 Delete, F9 Squeeze, F10 Quit. With Alt held the bar shows the keys' other meanings: Alt+F1 / Alt+F2 open the left / right pane's disk list; Alt+F5 gathers the marked files into a logical disk - a file written to the other pane's disk that the system mounts as a volume (MOUNT LD0: DZn:NAME.DSK, LD.SYS on the system disk; linear, no interleave, the format of PROGS.DSK); Alt+F6 protects the marked files, or unprotects them when every one is protected; Alt+F7 finds files by pattern on every mounted disk and goes to the one picked; Alt+F8 on an unused area undeletes the file it was - the system's DELETE leaves the name (shown after < UNUSED >), the length and the date in the entry, and the data lies there until something is written over the area. Enter on a logical disk enters it as if a directory (the pane headed DZn: disk: NAME, ".." or Backspace back out): its files are viewed, copied in and out, deleted there, the changes written back into the file on its disk (a file that does not fit makes the volume grow by what it needs - a logical disk is a file, and the system takes its size from the file's length); such a place is DZn:NAME.DSK/FILE in the dialogs. A protected file is deleted or moved only after one more Yes / No (Cancel and "the same for the other protected files" when several files are at hand). In the viewer: F1 the encoding (KOI-7 / KOI-8R / CP866), F2 wrap at 80 columns, F3 quit, F4 text / hex / octal, F5 go to a line, F7 search (a byte sequence in hex / octal); in the editor: F2 save, F8 replace / insert. The guest sees a change at its next directory read. Disks you write to stay in this browser (IndexedDB): "Download" saves a copy, "Revert" returns a shipped disk to its original, "Delete" removes one of yours. A game on osa.dsk: type R FIST (or open ?disk=osa.dsk&type=R%20FIST).
