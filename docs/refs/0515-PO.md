# МС0515 — Программы технического обслуживания

> **Источник**: OCR скана `scans/0515.rar` → `0515-ПО.pdf` (10 листов, 1991).
> Шифр документа: **.00103-01 96 01**
>
> Полное название: «Программы технического обслуживания. Руководство по
> техническому обслуживанию». Описывает встроенный диагностический пакет
> ПЭВМ «Электроника МС0515».

## Аннотация

Настоящий документ является руководством по работе с программами
технического обслуживания персональной ЭВМ «Электроника МС0515».

Документ содержит сведения о назначении программ и их функциях, состав
технических средств, необходимых для выполнения программ.

В разделе «Общие указания» приводится описание последовательности
действий по загрузке и запуску программ.

В разделах «Требования к техническим средствам» и «Требования к
программным средствам» указаны минимальный состав технических и
программных средств, необходимых для выполнения программ.

В разделе «Описание функций» приведено описание функционирования,
выполняемой и ожидаемой программ, а также тексты предлагаемых сообщений
и сообщений об ошибках, описание их содержания и соответствующих
действий оператора.

В приложении приведён каталог дискеты с тестовыми программами.

## 1. Введение

Руководство по техническому обслуживанию предназначено для использования
при проверке функционирования персональной ЭВМ «Электроника МС0515» и
дальнейшем поиске и устранении неисправностей, а также применении и
эксплуатации технических средств ПЭВМ.

В состав тестовых программ входят следующие программы:
- Программа **БСВВ** (Базовая система ввода/вывода)
- Программа **Упражнитель МС0515**

Программа **БСВВ** осуществляет следующие функции:

- проверяет центральный процессор (ЦП), оперативное запоминающее
  устройство (ОЗУ), видео-генерирующее запоминающее устройство (ВОЗУ),
  постоянное запоминающее устройство (ПЗУ), контроллёр накопителя на
  гибком магнитном диске (НГМД);
- вводит символы с клавиатуры;
- выводит сигналы на монитор;
- запускает операционную систему;
- управляет пультовым режимом.

Программа **Упражнитель МС0515** предназначена для проверки совместного
функционирования следующих устройств:

- ЦП;
- контроллёра НГМД;
- таймера;
- интерфейса последовательного типа ИЗ.

При техническом обслуживании ПЭВМ необходимо в данном документе
руководствоваться техническими описаниями и инструкциями по
эксплуатации персональной ЭВМ.

## 2. Общие указания

Для проведения технического обслуживания используется дискет
**«ПОЛОСА В1.0 Тестовые программы Дискет #1»**, в дальнейшем «Дискет #1».

### 2.1. Загрузка и запуск программы «Упражнитель МС0515»

Для загрузки и запуска программы используется операционная система **ОСА**.

Возможны два способа загрузки операционной системы:

**Первый способ:**

1. Выключить питание.
2. Вставить дискет #1 в привод.

Загрузка и запуск операционной системы начинается с выводом сообщения:

```
ОСА  Версия 1.0
```

По выполнению выводится точка 1.1, которая означает готовность монитора
проверять команды с терминала.

**Второй способ:**

1. Выключить питание.
2. После выхода программы БСВВ в режим пульта вставить дискет #1 в
   привод. Передать команду пультового режима:

После загрузки и оперативной памяти системы программа «Упражнитель
МС0515» запускается нажатием на любую клавишу в основном алфавите.

```
.R 183107.SAV
```

После загрузки программа выходит на работу.

## 5. Описание функций

Для проверки функционирования ПЭВМ используются следующие программы:
- Программа БСВВ;
- Упражнитель МС0515.

### 5.1. Программа БСВВ

#### 5.1.1. Описание функционирования программы

Программа БСВВ, записанная в **ПЗУ**, автоматически выполняется каждый
раз после включения питания без использования других программных
средств. Она проверяет основное, дополнительное и видео-ОЗУ,
центральный процессор, ПЗУ, клавиатуру, контроллёр НГМД; производит
ввод сигналов с клавиатуры и вывод их на монитор; управляет пультовым
режимом; производит загрузку операционной системы (загрузчика) в ОЗУ и
запускает загрузочную программу.

На монитор выводятся сообщения, подтверждающие состояние ПЭВМ.

**Приём сообщений, выводимых на монитор после включения питания
или перезапуска программы:**

```
Клавиатура готова
```

```
Электроника
```

```
Тест ОЗУ
Без дефектов
Основное          Ёх Кбайт
Дополнительное    Ёх Кбайт
Дополнительное     Ёх Кбайт
```

```
Тест ПЗУ
Без дефектов
```

```
НГМД не готов — ПУЛЬТОВЫЙ РЕЖИМ
```

При отсутствии дискеты в системном приводе программа БСВВ переходит в
пультовый режим и ожидает ввода команд оператора (см. п.5.1.3).

Для пультового запуска программы БСВВ из пультового режима подайте
команду:

```
.81708080
```

Если дискет в системный считается в приводе, загрузка операционной
системы происходит автоматически без вмешательства оператора.

##### 5.1.1.1. Проверка памяти

Проверка ОЗУ производится по записи в каждый из килобайт по образцам
К=0..177777, ВОЗУ производится по образцам 13777 и далее в основном
запоминающемся устройстве 65000..177777.

После завершения проверки выводится сообщение:

```
Тест ОЗУ
Без дефектов
```

```
Основное          Ёх Кбайт
Дополнительное    Ух Кбайт
Дополнительное    Ёх Кбайт
```

где: Ёх, Ух, Zz — ёмкость указанной памяти.

##### 5.1.1.2. Проверка ЦП

После проверки команд ЦП на мониторе выводится сообщение:

```
Тест процессора
```

После начала которого происходит выполнение команд ЦП. При обнаружении
ошибки выводится сообщение:

```
Дефект
```

и программа возвращается из цикла. При отсутствии ошибок выводится
сообщение:

```
Без дефектов
```

##### 5.1.1.3. Проверка ПЗУ

Перед проверкой ПЗУ выводится сообщение:

```
Тест ПЗУ
```

Проверяется правильность контрольной суммы ПЗУ и при
несоответствии с заводской паспорту выводится сообщение «Дефект»,
сопровождаемое звуковыми сигналами.

##### 5.1.1.4. Проверка устройства звуковоспроизведения

Проверка начинается с выводом «звукового», подтверждающего
работоспособность устройства.

##### 5.1.1.5. Проверка клавиатуры

Проверяется наличие клавиатуры. Если клавиатура подключена,
выводится сообщение:

```
Клавиатура готова
```

Если клавиатура не подключена, выводится сообщение «Клавиатура
не готова», сопровождаемое звуковыми сигналами.

##### 5.1.1.6. Проверка контроллёра НГМД

Программа проверяет правильность выполнения команд:
- чтение номера дорожки дискета;
- сброс НГМД;
- шаг вперёд без записи;
- поиск;
- шаг назад без записи;

и выводит сообщение:

```
НГМД готов, идёт загрузка операционной системы...
```

В случае ошибки выводится мерцающее сообщение «НГМД не
готов — ПУЛЬТОВЫЙ РЕЖИМ», сопровождаемое звуковыми сигналами.

#### 5.1.2. Сообщения об ошибках

Если после включения питания изображение на мониторе не появляется в
течение 2 минут, отрегулируйте яркость и контрастность вашего монитора.

##### 5.1.2.1. Дефект

Выводится при несоответствии контрольной суммы ПЗУ или обнаружении
ошибок при выполнении команд ЦП.

##### 5.1.2.2. Клавиатура не готова

Выводится, если не подключена клавиатура.

#### 5.1.3. Команды пультового режима

| Команда | Действие |
|---------|----------|
| `B`     | загрузка с гибкого диска |
| `L`     | загрузка с магнитофона |
| `M`     | режим средневероятностного эквивалента — XX (ВВ) знаков |
| `D`     | продолжить выполнение программы с точки остановки |
| `НВ`    | запустить программу с адреса XX |
| `XX`    | открыть ячейку с адресом XX |
| `/`     | открыть следующую ячейку |
| `(°`    | открыть предыдущую ячейку |
| `<ВК>`  | закрыть ячейку |
| `J`     | открыть ячейку, которая была вызвана последней |
| `<ЗБ>`  | необходимое сначала слева до маршрута |
| `<СВ>`  | сдвиг каретки влево на 1 знак |
| `КВ`    | для отображения цвета RGB и Z |
| `(М)`   | цвет точки фона в рисунка в режиме среднего разрешения (М — задаёт цвет точки фона ;<br>J — задаёт цвет точки рисунка M, J от 0 до 7) |

формат `N,M,J`:

```
N       цвет
0       чёрный
1       синий
2       красный
3       пурпурный
4       зелёный
5       голубой
6       жёлтый
7       белый
```

### 5.2. Программа «Упражнитель МС0515»

#### 5.2.1. Описание функционирования программы

Программа «Упражнитель МС0515» используется для проверки совместно
ЦП, таймера, контроллёра НГМД, интерфейса последовательного
обмена. Программа выполняется автоматически. При обнаружении ошибки
выводятся сообщения, описанные в п.5.2.4.

Время выполнения одного прохода программы приблизительно равно 5 мин.

После загрузки и запуска программы выводит сообщение:

```
УПРАЖНИТЕЛЬ МС0515 В1.0
ЗАДАТЬ РЕЖИМ РАБОТЫ В РУЧКЕ 081074
И НАЖАТЬ КЛАВИШУ Р
```

и приступает загрузку по адресу 081174.

Завершите в ячейку 081174 восьмеричное число, определяющее
необходимый режим работы. При обращении к нему ниже, таблиц. 1).

Если задана проверка НГМД, занесите системный дискет в
рабочий. Если задана проверка интерфейса, установите сервисную
розетку. Для продолжения программы нажмите клавишу 'Р'
латинского алфавита.

После очередного прохода программы выводится сообщение в одной
строке:

```
ПРОХОД  N
ОНО ХУ УУУУУУ ПРЕРЫВАНИЕ ZZZZZZ
ОНО ИНТЕРФ. ЗSSSSSS ОНО ИНТЕРФЕЙСА XXXXXX
```

где:
- `N` — номер очередного прохода;
- `УУУУУУ` — число обнаруженных ошибок при проверке команд ЦП;
- `ZZZZZZ` — число прерываний от таймера;

```
НГМД
SSSSSS — число обнаруженных ошибок при проверке
последовательного интерфейса.
```

При отсутствии ошибок значения УУУУУУ, ZZZZZZ, SSSSSS должны
быть равны 000000, а ZZZZZZ не равно нулю.

##### 5.2.1.1. Проверка команд ЦП

Проверка команд ЦП состоит из малых тестов, каждый из которых
проверяет конкретную команду. Тесты выполняются последовательно, во
ожидаемом выполнении которых выводится сообщение в одной строке.
При обнаружении ошибок выводится сообщение п.5.2.4.1.

##### 5.2.1.2. Проверка таймера

В начале программы разрешаются прерывания от таймера. По мере
прохода программы ЦП происходит прерывание от таймера. Их число
соответствуется и по завершению прохода программы выводится в
сообщении в одной строке.

##### 5.2.1.3. Проверка контроллёра НГМД

Производится запись данных на дискете и чтение данных в
оперативную память.  За один проход производится 256 циклов записи и
чтения.

##### 5.2.1.4. Проверка последовательного интерфейса

Проверяется передача и приём данных в режиме применения
использования сервисной розетки.

#### 5.2.2. Режим работы

Режим работы программы определяется значением разрядов программного
переключателя режима (ПР), расположенного в ячейке 081174 (см.
табл.1).

Переключатель содержится ПР равен 000010.

**ТАБЛИЦА 1**

| Разряд ПР | Значение ПР | Режим работы |
|-----------|-------------|--------------|
| 14        | 100000      | Остановка по ошибке |
| 13        | 040000      | Зацикливание малого теста |
| 12        | 020000      | Зацикливание выдачи сообщения об ошибке |
| 11        | 010000      | Зацикливание программы малого теста |
| 11        | 4000        | Зацикливание выдачи каждого теста |
| 10        | 400         | Зацикливание накопления команд НГМД |
| 03        | 10          | Зацикливание проверки последовательного интерфейса |
| 02        | 4           | Зацикливание проверки контроллера НГМД |
| 01        | 2           | Зацикливание таймера |

**Примечание.** Для замечания режима работы во время выполнения
программы нажмите клавишу "К". Происходит останов по адресу 7050.
Заметите в ячейку 081174 необходимое число, для продолжения
программы нажмите клавишу "Т" латинского алфавита. Для продолжения
программы, прерванной по `(M.0L)`, нажав
"М" значение выдачи тестовой программы.

Если PR(R0)=0, то при обнаружении ЗВ ошибки устройства, оно
исключается из проверки.

#### 5.2.3. Завершение программы

Для завершения выполнения тестовой программы нажмите клавишу
'X'. Программа выходит в монитор.

#### 5.2.4. Сообщения об ошибках

##### 5.2.4.1. CR XXXXX MOD YYYYYY OWNZ ZZZZZZ

где:
- `XXXXX` — счётчик команд в момент ошибки;
- `YYYYYY` — содержимое регистра системного процессора в момент ошибки;
- `ZZZZZZ` — командный адрес малого теста, обнаружившего ошибку.

Выводится при обнаружении ошибки ЦП.

##### 5.2.4.2. (Признак ошибки)

Выводится при обнаружении ошибки функционирования контроллера НГМД
и составной:

Например:

```
НГМД  ОНО ЗАПИСИ
```
