- РЕДАКТОР ШАБЛОНОВ ДОКУМЕНТОВ;

- ГеНЕРАТОР ДОКУМЕНТОВ (СМ. РЕЛЯЦИОННАЯ СУБД ДЛЯ МИКРО-ЭВМ, РУКОВОДСТВО ОПЕРАТОРА).

ОТЛИЧИТЕЛЬНОЙ ОСОБЕННОСТЬЮ ДАННЫХ СРЕДСТВ ГЕНЕРАЦИИ ЯВЛЯЕТСЯ ВОЗМОЖНОСТЬ ИСПОЛЬЗОВАНИЯ В ДОКУМЕНТАХ ИНФОРМАЦИИ ИЗ БАЗЫ ДАННЫХ.

## РЕДАКТОР ШАБЛОНОВ ДОКУМЕНТОВ

### НАЗНАЧЕНИЕ

РЕДАКТОР EDDOC ПРЕДНАЗНАЧЕН ДЛЯ ВВОДА И РЕДАКТИРОВАНИЯ В ДИАЛОГОВОМ РЕЖИМЕ ШАБЛОНОВ ДОКУМЕНТОВ ШИРИНОЙ ДО 156 СИМВОЛОВ С ПОСЛЕДУЮЩИМ ВЫВОДОМ ИХ ГЕНЕРАТОРОМ ДОКУМЕНТОВ НА ВНЕШНИЕ УСТРОЙСТВА.

### ОКНА ШАБЛОНА

ШАБЛОН ДОКУМЕНТА МОЖЕТ СОДЕРЖАТЬ ИЗМЕНЯЕМУЮ ЧАСТЬ - ОКНА, КОТОРЫЕ ВЫДЕЛЯЮТСЯ НАЖАТИЕМ ФУНКЦИОНАЛЬНОЙ КЛАВИШИ "ВЫДЕЛЕНИЕ ОКНА". КОЛИЧЕСТВО НАЖАТИЙ КЛАВИШИ "ВЫДЕЛЕНИЕ ОКНА" ОПРЕДЕЛЯЕТ ШИРИНУ ОКНА ШАБЛОНА, КОТОРОЕ НА ЭКРАНЕ ДИСПЛЕЯ ОТОБРАЖАЕТСЯ ПОСЛЕДОВАТЕЛЬНОСТЬЮ СИМВОЛОВ "#".

ИНФОРМАЦИЯ, ПОМЕЩАЕМАЯ В ОКНА, ВВОДИТСЯ С КЛАВИАТУРЫ ДИСПЛЕЯ ИЛИ ВЫБИРАЕТСЯ ИЗ БАЗЫ ДАННЫХ НА ЭТАПЕ ГЕНЕРАЦИИ ДОКУМЕНТОВ.

СУЩЕСТВУЕТ ЧЕТЫРЕ ТИПА ОКОН:

**ТИП ОКНА "Д"**

ЗАПОЛНЯЕТСЯ ПОЛЬЗОВАТЕЛЕМ В ДИАЛОГОВОМ РЕЖИМЕ;

**ТИП ОКНА "Б"**

ЗАПОЛНЯЕТСЯ ИНФОРМАЦИЕЙ ИЗ БАЗЫ ДАННЫХ;

**ТИП ОКНА "Н"**

ПРЕДНАЗНАЧЕН ДЛЯ НУМЕРАЦИИ ВЫВОДИМЫХ ЗАПИСЕЙ ИЗ БАЗЫ ДАННЫХ;

**ТИП ОКНА "Ф"**

СОДЕРЖИТ РЕЗУЛЬТАТ ВЫЧИСЛЕНИЯ АРИФМЕТИЧЕСКИХ ВЫРАЖЕНИЙ НАД ДАННЫМИ И БАЗЫ ДАННЫХ.

### ПОВТОРЯЕМЫЙ ФРАГМЕНТ ШАБЛОНА

ЕСЛИ ШАБЛОН СОДЕРЖИТ ИНФОРМАЦИЮ ИЗ БАЗЫ ДАННЫХ И НЕКОТОРУЮ ЧАСТЬ ЕГО ТРЕБУЕТСЯ ПОВТОРИТЬ ДЛЯ ВСЕХ АКТИВНЫХ ЗАПИСЕЙ БАЗЫ ДАННЫХ (СМ. РЕЛЯЦИОННАЯ СУБД ДЛЯ МИКРО-ЭВМ, РУКОВОДСТВО ОПЕРАТОРА), ТО ЭТА ЧАСТЬ ШАБЛОНА ЗАКЛЮЧАЕТСЯ В УПРАВЛЯЮЩИЕ СТРОКИ: "(#" - В НАЧАЛЕ И "#)" - В КОНЦЕ. ТАКОЙ ФРАГМЕНТ НАЗЫВАЕТСЯ ПОВТОРЯЕМЫМ ФРАГМЕНТОМ ШАБЛОНА, НАПРИМЕР:

```
------------------------------
!  N  !  ФАМИЛИЯ  !  ПРЕМИЯ  !
------------------------------
(#
!#####!###########!##########!
#)
```

ЕСЛИ ШАБЛОН СОДЕРЖИТ ОКНА ТИПА "Б" ИЛИ "Н", ТО ОНИ ОБЯЗАТЕЛЬНО ВХОДЯТ В СОСТАВ ПОВТОРЯЕМОГО ФРАГМЕНТА ШАБЛОНА.

ОПРЕДЕЛЕНЫ ДВА ТИПА ПОВТОРЯЕМОГО ФРАГМЕНТА ШАБЛОНА:
- ПОВТОРЯЕМЫЙ ФРАГМЕНТ ШАБЛОНА С ПЕРЕНОСОМ;
- ПОВТОРЯЕМЫЙ ФРАГМЕНТ ШАБЛОНА С ОБРЕЗАНИЕМ.

ЕСЛИ ВЫВОДИМЫЙ ТЕКСТ В ОКНА НЕ ПОМЕЩАЕТСЯ, А ЕГО ТРЕБУЕТСЯ НАПЕЧАТАТЬ ПОЛНОСТЬЮ, ТО ИСПОЛЬЗУЕТСЯ ПОВТОРЯЕМЫЙ ФРАГМЕНТ ШАБЛОНА С ПЕРЕНОСОМ. ОН В ТЕКСТЕ ВЫДЕЛЯЕТСЯ ФУНКЦИОНАЛЬНЫМИ СТРОКАМИ: "(#" - В НАЧАЛЕ И "#)" - В КОНЦЕ. ВТОРОЙ ТИП ПОВТОРЯЕМОГО ФРАГМЕНТА ШАБЛОНА В ТЕКСТЕ ВЫДЕЛЯЕТСЯ ФУНКЦИОНАЛЬНЫМИ СТРОКАМИ: "(#О" - В НАЧАЛЕ И "#)" - В КОНЦЕ.

ДОКУМЕНТ МОЖЕТ ПЕЧАТАТЬСЯ ЛИСТАМИ. ДЛЯ ТОГО, ЧТОБЫ В НАЧАЛЕ КАЖДОГО ЛИСТА ПЕЧАТАЛАСЬ ШАПКА ДОКУМЕНТА, ТЕКСТ В ДОКУМЕНТЕ ЗАКЛЮЧАЕТСЯ В УПРАВЛЯЮЩИЕ СТРОКИ "(#{" - В НАЧАЛЕ И "#)" - В КОНЦЕ.

ЕСЛИ НЕКОТОРЫЙ ФРАГМЕНТ ТЕКСТА НЕОБХОДИМО ПЕЧАТАТЬ В КОНЦЕ КАЖДОГО ЛИСТА, ТО ОН ЗАКЛЮЧАЕТСЯ В УПРАВЛЯЮЩИЕ СТРОКИ "(#К" - В НАЧАЛЕ И "#)" - В КОНЦЕ.

```
(#{
--------------------------------------------------
!  N  !    ФАМИЛИЯ    !  ГОД РОЖДЕНИЯ  !  ОКЛАД  !
--------------------------------------------------
#)
(#К
--------------------------------------------------
#)
(#
!#####!###############!################!#########!
#)
```

# ОБРАЩЕНИЕ К ПРОГРАММЕ

## СХЕМА РАБОТЫ РЕДАКТОРА

ВЫЗОВ РЕДАКТОРА ШАБЛОНОВ EDDOC С СИСТЕМНОГО УСТРОЙСТВА ОСУЩЕСТВЛЯЕТСЯ КОМАНДОЙ

```
.R EDDOC
```

РЕДАКТОР ЗАПРАШИВАЕТ ИМЯ ВХОДНОГО ФАЙЛА:

```
ВХОДНОЙ ФАЙЛ? <ИМЯ ФАЙЛА>
```

ГДЕ <ИМЯ ФАЙЛА> - ВВОДИМОЕ С КЛАВИАТУРЫ ДИСПЛЕЯ ИМЯ РЕДАКТИРУЕМОГО ФАЙЛА.

ПРИ НАЖАТИИ КЛАВИШИ "ВК" РЕДАКТОР ЗАНОВО СОЗДАЕТ ФАЙЛ.

ПОСЛЕ ЗАДАНИЯ ИМЕНИ ВХОДНОГО ФАЙЛА ЗАПРАШИВАЕТСЯ ИМЯ ВЫХОДНОГО ФАЙЛА:

```
ВЫХОДНОЙ ФАЙЛ? <ИМЯ ФАЙЛА>
```

ПО НАЖАТИЮ КЛАВИШИ "ВК" ИМЕНИ ВЫХОДНОГО ФАЙЛА ПРИСВАИВАЕТСЯ ИМЯ ВХОДНОГО. ЕСЛИ ПРИ ЭТОМ ИМЯ ВХОДНОГО ФАЙЛА НЕ БЫЛО ЗАДАНО, ТО ВЫДАЕТСЯ ВЕРСИЯ ПРОГРАММЫ И ЗАПРОСЫ НА ВВОД ИМЕН ФАЙЛОВ ПОВТОРЯЮТСЯ.

ПРИ СОЗДАНИИ ФАЙЛА РЕДАКТОР ЗАПРАШИВАЕТ ШИРИНУ ДОКУМЕНТА:

```
ШИРИНА ДОКУМЕНТА?
```

ЕСЛИ ВХОДНОЙ ФАЙЛ НЕ НАЙДЕН, ВЫДАЕТСЯ СООБЩЕНИЕ:

```
ФАЙЛ НЕ НАЙДЕН
```

И ПОВТОРНО ЗАПРАШИВАЕТСЯ ИМЯ ВХОДНОГО ФАЙЛА.

ПРИ ЗАДАНИИ ИМЕНИ ВХОДНОГО ФАЙЛА ДОПУСКАЕТСЯ ИСПОЛЬЗОВАНИЕ КЛЮЧА /R. ЭТОТ КЛЮЧ НЕОБХОДИМ ПРИ РАБОТЕ РЕДАКТОРА НА ТЕРМИНАЛАХ, В КОТОРЫХ ОТСУТСТВУЕТ СДВИГ ЭКРАНА ВНИЗ (НАПРИМЕР, ВТА 2000-30). ЕСЛИ КЛЮЧ /R ЗАДАН, ТО СДВИГ ЭКРАНА ВНИЗ МОДЕЛИРУЕТСЯ ПЕРЕВЫВОДОМ ИНФОРМАЦИИ НА ЭКРАНЕ.

РЕДАКТОР СОЗДАЕТ ПО УМОЛЧАНИЮ ВЫХОДНОЙ ФАЙЛ С РАСШИРЕНИЯМИ .TXD.

ПРИ РЕДАКТИРОВАНИИ УЖЕ СОЗДАННОГО ШАБЛОНА ФАЙЛ СЧИТЫВАЕТСЯ В ОПЕРАТИВНУЮ ПАМЯТЬ И НА ЭКРАН ДИСПЛЕЯ ВЫВОДЯТСЯ ПЕРВЫЕ 23 СТРОКИ ТЕКСТА ШАБЛОНА.

ПРИ СОЗДАНИИ НОВОГО ФАЙЛА ЭКРАН ГАСИТСЯ И ВЫПОЛНЯЕТСЯ ВВОД ТЕКСТА.

ПОЗИЦИЯ ВВОДА И РЕДАКТИРОВАНИЯ ОПРЕДЕЛЯЕТСЯ ПОЛОЖЕНИЕМ МАРКЕРА.

ПРИ РЕДАКТИРОВАНИИ СОЗДАННОГО ТЕКСТА ШАБЛОНА БЛОКИРУЕТСЯ РАЗДЕЛЕНИЕ ОДНОГО ОКНА НА ДВА И СЛИЯНИЕ ДВУХ ОКОН В ОДНО.

ПОСЛЕ СОЗДАНИЯ ТЕКСТА ШАБЛОНА НАЖАТИЕМ КЛАВИШИ "ОПИСАНИЕ ОКОН" ОСУЩЕСТВЛЯЕТСЯ ПОСЛЕДОВАТЕЛЬНОЕ ОПРЕДЕЛЕНИЕ ВСЕХ ОКОН ШАБЛОНА, ПРИ РЕДАКТИРОВАНИИ - ТОЛЬКО ВНОВЬ СОЗДАННЫХ.

РЕДАКТОР ПОЗВОЛЯЕТ ПЕРЕОПИСЫВАТЬ ОКНА С СОХРАНЕНИЕМ ТЕКСТА ШАБЛОНА. ПОЭТОМУ ПОСЛЕ ОПИСАНИЯ ОКОН ЗАПРАШИВАЕТСЯ:

```
БУДЕТЕ КОРРЕКТИРОВАТЬ ОПИСАНИЕ ОКОН(Д/Н)?
```

ПРИ ОТРИЦАТЕЛЬНОМ ОТВЕТЕ ШАБЛОН ЗАПИСЫВАЕТСЯ НА ВНЕШНИЙ НОСИТЕЛЬ.

ПРИ УТВЕРДИТЕЛЬНОМ ОТВЕТЕ РЕДАКТОР ВЫХОДИТ НА РЕЖИМ КОРРЕКТИРОВКИ ОПИСАНИЯ ОКОН. ДЛЯ ПЕРЕОПИСАНИЯ ОКНА НЕОБХОДИМО ПОДВЕСТИ КУРСОР К НУЖНОМУ ОКНУ И НАЖАТЬ КЛАВИШУ "ПЕРЕОПИСАНИЕ ОКНА". ПРИ ЭТОМ ПРЕЖНЕЕ ОПИСАНИЕ ОКНА УДАЛЯЕТСЯ И РЕДАКТОР ВЫХОДИТ НА ЕГО ПЕРЕОПИСАНИЕ.

ВЫХОД ИЗ РЕЖИМА "КОРРЕКТИРОВКИ И ОПИСАНИЯ ОКОН" ОСУЩЕСТВЛЯЕТСЯ НАЖАТИЕМ КЛАВИШИ "ОПИСАНИЕ ОКОН". ПОСЛЕ ЭТОГО РЕДАКТОР ПОВТОРНО ЗАПРАШИВАЕТ НЕОБХОДИМОСТЬ КОРРЕКТИРОВКИ ОПИСАНИЯ ОКОН.

## ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ РЕДАКТОРА

ДЛЯ РАБОТЫ С РЕДАКТОРОМ EDDOC ИСПОЛЬЗУЮТСЯ ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ, КОТОРЫЕ В ТЕКСТЕ ДАННОГО ДОКУМЕНТА ПРЕДСТАВЛЕНЫ ВЗЯТЫМИ В КАВЫЧКИ ИМЕНАМИ, НАПРИМЕР "СТРЕЛКА ВВЕРХ". СООТВЕТСТВУЮЩИЕ  ИМ  КОНКРЕТНЫЕ КЛАВИШИ ДИСПЛЕЯ ПРИВЕДЕНЫ В ПРИЛОЖЕНИИ,  ПРИ  ЭТОМ  РЯД  ДЕЙСТВИЙ ЗАДАЕТСЯ ПОСЛЕДОВАТЕЛЬНЫМ НАЖАТИЕМ ДВУХ КЛАВИШ.

КРОМЕ ТОГО ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ ПРОДУБЛИРОВАННЫ АЛФАВИТНЫМИ КЛАВИШАМИ, НАЖИМАЕМЫМИ СОВМЕСТНО С  УПРАВЛЯЮЩЕЙ  КЛАБИШЕЙ  "CTRL" (НА НЕКОТОРЫХ ТИПАХ ДИСПЛЕЕВ ЭТА КЛАВИША  ОБОЗНАЧАЕТСЯ  КАК  "СУ", "УС", "СЛУЖ.КОД"), ЭТО ПОЗВОЛЯЕТ ИСПОЛЬЗОВАТЬ РЕДАКТОР EDDOC БЕЗ ПЕРЕНАСТРОЙКИ ПОД КОНКРЕТНЫЕ КОДЫ КЛАВИАТУРЫ НА БОЛЬШИНСТВЕ ТИПОВ ДИСПЛЕЕВ.

ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ:

**"СТРЕЛКА ВВЕРХ"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА НА ОДНУ СТРОКУ ВВЕРХ. ПРИ ПОЛОЖЕНИИ МАРКЕРА В ВВЕРХНЕЙ СТРОКЕ ТЕКСТ НА ЭКРАНЕ СДВИГАЕТСЯ НА ОДНУ СТРОКУ ВНИЗ И В ВЕРХНЮЮ СТРОКУ ВЫВОДИТСЯ ПРЕДЫДУЩЯЯ СТРОКА ТЕКСТА;

**"СТРЕЛКА ВНИЗ"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА НА ОДНУ СТРОКУ ВНИЗ. ПРИ ПОЛОЖЕНИИ МАРКЕРА В НИЖНЕЙ СТРОКЕ ТЕКСТ  НА ЭКРАНЕ СДВИГАЕТСЯ НА ОДНУ СТРОКУ ВВЕРХ И В НИЖНЮЮ СТРОКУ ВЫВОДИТСЯ СЛЕДУЮЩАЯ СТРОКА ТЕКСТА;

**"СТРЕЛКА ВПРАВО"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА НА ОДНУ ПОЗИЦИЮ  ПО  СТРОКЕ ВПРАВО;

**"СТРЕЛКА ВЛЕВО"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА НА ОДНУ ПОЗИЦИЮ ПО СТРОКЕ ВЛЕВО;

**"ВСТАВИТЬ СТРОКУ"**

ВСТАВКА ПУСТОЙ СТРОКИ;

**"УДАЛИТЬ СТРОКУ"**

УДАЛЕНИЕ ТЕКУЩЕЙ СТРОКИ;

**"ВСТАВИТЬ СИМВОЛ"**

ВСТАВКА ПРОБЕЛА. СИМВОЛЫ СПРАВА ОТ МАРКЕРА СДВИГАЮТСЯ ВПРАВО НА 1

**"УДАЛИТЬ СИМВОЛ"**

УДАЛЕНИЕ ТЕКУЩЕГО СИМВОЛА

**"В НАЧАЛО СТРОКИ"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА В НАЧАЛО ТЕКУЩЕЙ СТРОКИ ЭКРАНА;

**"В КОНЕЦ СТРОКИ"**

ПЕРЕМЕЩЕНИЕ МАРКЕРА В КОНЕЦ ТЕКУЩЕЙ СТРОКИ ЭКРАНА;

**"ДУБЛЬ СТРОКИ"**

ДУБЛИРОВАНИЕ ПРЕДЫДУЩЕЙ СТРОКИ;

**"ПС"**

КОНЕЦ СТРОКИ ТЕКСТА. ПЕРЕМЕЩЕНИЕ МАРКЕРА В НАЧАЛО СЛЕДУЮЩЕЙ СТРОКИ;

**"ЗАБОЙ"**

УДАЛЕНИЕ СИМВОЛА ПЕРЕД МАРКЕРОМ;

**"В НАЧАЛО ШАБЛОНА"**

## ОПИСАНИЕ ОКОН ШАБЛОНА

ПО НАЖАТИИ КЛАВИШИ "ОПИСАНИЕ ОКОН" ВЫПОЛНЯЕТСЯ ОПИСАНИЕ ОКОН ШАБЛОНА. ЭКРАН ГАСИТСЯ И ВЫДАЕТСЯ ЗАПРОС:

```
БУДЕТЕ РАБОТАТЬ С БАЗОЙ ДАННЫХ (Д/Н)?
```

ПРИ РАБОТЕ С РАНЕЕ СОЗДАННЫМ ШАБЛОНОМ, СОДЕРЖАЩИМ ОПИСАНИЕ БД ЗАПРОС НА РАБОТУ С БАЗОЙ ДАННЫХ ОТСУТСТВУЕТ.

ПРИ УТВЕРДИТЕЛЬНОМ ОТВЕТЕ РЕДАКТОР ЗАПРАШИВАЕТ ИМЯ БАЗЫ ДАННЫХ:

```
ИМЯ БАЗЫ ДАННЫХ? <ИМЯ>
```

ЕСЛИ ПРИ СОЗДАНИИ ШАБЛОНА ИМЯ БАЗЫ ДАННЫХ ЗАДАНО НЕВЕРНО, НА ЭКРАН ВЫДАЕТСЯ СООБЩЕНИЕ:

```
БАЗА ДАННЫХ НЕ НАЙДЕНА
```

И ПОВТОРНО ЗАПРАШИВАЕТСЯ  ИМЯ БАЗЫ ДАННЫХ.

ПРИ РАБОТЕ С РАНЕЕ СОЗДАННЫМ ШАБЛОНОМ, СОДЕРЖАЩИМ ОПИСАНИЕ БАЗЫ ДАННЫХ, В СЛУЧАЕ НЕ СООТВЕТСТВИЯ ЕГО ИСПОЛЬЗУЕМОЙ БАЗОЙ ДАННЫХ ВЫДАЕТСЯ СООБЩЕНИЕ:

```
ИНИЦИАЛИЗИРУЕМАЯ БД НЕ СООТВЕТСТВУЕТ ИСПОЛЬЗУЕМОЙ
БД В ШАБЛОНЕ
```

И РЕДАКТОР ЗАПРАШИВАЕТ:

```
ПЕРЕПИСАНИЕ ВСЕХ ОКОН С ИНИЦИАЛИЗИРУЕМОЙ БД (Д/Н)?
```

ПРИ ОТРИЦАТЕЛЬНОМ ОТВЕТЕ ПОВТОРНО ЗАПРАШИВАЕТСЯ ИМЯ БАЗЫ ДАННЫХ.

ПРИ УТВЕРДИТЕЛЬНОМ - РЕДАКТОР ВЫХОДИТ В РЕЖИМ СОЗДАНИЯ ШАБЛОНА С ПЕРЕОПИСАНИЕМ ВСЕХ ОКОН.

ЕСЛИ БАЗА ДАННЫХ ЗАЩИЩЕНА ПАРОЛЕМ, РЕДАКТОР ЗАПРАШИВАЕТ:

```
ПАРОЛЬ?
```

ПРИ ПРАВИЛЬНОМ ВВОДЕ ПАРОЛЯ ЭКРАН ГАСИТСЯ И ВЫВОДИТСЯ ПЕРВАЯ 21 СТРОКА ШАБЛОНА. 22-Я И 23-Я СТРОКИ ЭКРАНА ДИСПЛЕЯ ВЫДЕЛЯЮТСЯ ПОД ДИАЛОГ ПОЛЬЗОВАТЕЛЯ С РЕДАКТОРОМ.

ПРОИСХОДИТ ПОСЛЕДОВАТЕЛЬНОЕ ОПИСАНИЕ ОКОН ШАБЛОНА. ОКНО, ОПИСАНИЕ КОТОРОГО ВЫПОЛНЯЕТСЯ В ТЕКУЩИЙ МОМЕНТ, ВЫДЕЛЯЕТСЯ СИМВОЛАМИ "$".

В СТРОКЕ ДИАЛОГА РЕДАКТОР ЗАПРАШИВАЕТ:

```
ТИП ОКНА (Б/Д/Н/Ф)?
```

ЕСЛИ ОКНО ОПРЕДЕЛЕНО ПОЛЬЗОВАТЕЛЕМ КАК ТИП "Д", РЕДАКТОР В ДИАЛОГОВОЙ СТРОКЕ ЗАПРАШИВАЕТ:

```
ТЕКСТ ЗАПРОСА?
```

ЭТОТ ЗАПРОС В ДАЛЬНЕЙШЕМ БУДЕТ ВЫДАВАТЬСЯ НА ЭКРАН ПРИ ГЕНЕРАЦИИ ДОКУМЕНТОВ ДЛЯ ВВОДА ЗНАЧЕНИЯ ОКНА.

ЕСЛИ ПОЛЬЗОВАТЕЛЬ НЕ БУДЕТ РАБОТАТЬ С БАЗОЙ ДАННЫХ, ЗАПРОС НА ТИП ОКНА ОТСУТСТВУЕТ.

ЕСЛИ ОКНО ОПРЕДЕЛЕНО КАК ТИП  "Б", РЕДАКТОР ЗАПРАШИВАЕТ:

```
ИМЯ СТОЛБЦА БАЗЫ ДАННЫХ?
```

И В ТОЙ ЖЕ СТРОКЕ ПОСЛЕ ЗАПРОСА ВЫВОДИТ НА ЭКРАН ИМЯ ПЕРВОГО СТОЛБЦА БАЗЫ ДАННЫХ.

ИМЕНА СТОЛБЦОВ МОЖНО ПРОСМАТРИВАТЬ В РЕЖИМЕ "РОЛИКА". НАЖАТИЕМ ФУНКЦИОНАЛЬНОЙ КЛАВИШИ "СТРЕЛКА ВНИЗ" В ДИАЛОГОВОЙ СТРОКЕ ВЫВОДЯТСЯ ИМЕНА СТОЛБЦОВ, СЛЕДУЮЩИЕ ПО ПОРЯДКУ ВОЗРАСТАНИЯ ИХ НОМЕРОВ. НАЖАТИЕМ КЛАВИШИ "СТРЕЛКА ВВЕРХ" ИМЕНА СТОЛБЦОВ ВЫВОДЯТСЯ В ОБРАТНОМ ПОРЯДКЕ.

НАЖАТИЕМ КЛАВИШИ "ВК" ПОЛЬЗОВАТЕЛЬ ОПРЕДЕЛЯЕТ СТОЛБЕЦ, ИЗ КОТОРОГО БУДЕТ ЗАПОЛНЯТЬСЯ СООТВЕТСТВУЮЩЕЕ ОКНО. ЕСЛИ ВЫБРАННЫЙ СТОЛБЕЦ ИМЕЕТ ВЕЩЕСТВЕННЫЙ ТИП, ТО ЗАПРАШИВАЕТСЯ ФОРМАТ ВЫВОДА:

```
ЧИСЛО ВЫВОДИТСЯ В ФОРМАТЕ С ФИКСИРОВАННОЙ ТОЧКОЙ (Д/Н)?
```

И В СЛУЧАЕ ИСПОЛЬЗОВАНИЯ ФОРМАТА С ФИКСИРОВАННОЙ ТОЧКОЙ ЗАПРАШИВАЕТСЯ ЧИСЛО ЦИФР, ВЫВОДИМЫХ ПОСЛЕ ТОЧКИ:

```
ЧИСЛО ЦИФР ПОСЛЕ ТОЧКИ?
```

В ПОВТОРЯЕМОМ ФРАГМЕНТЕ ШАБЛОНА СУЩЕСТВУЕТ ВОЗМОЖНОСТЬ В НЕСКОЛЬКИХ ОКНАХ ПОМЕЩАТЬ ИНФОРМАЦИЮ ИЗ ОДНОГО И ТОГО ЖЕ СТОЛБЦА. ЕСЛИ ПОМЕЩАЕМАЯ В ОКНО ИНФОРМАЦИЯ ЯВЛЯЕТСЯ ПРОДОЛЖЕНИЕМ РАННЕЕ ОПРЕДЕЛЕННОГО ОКНА, ТО ПОСЛЕ ВЫБОРА ИМЕНИ СТОЛБЦА НАЖАТИЕМ КЛАВИШИ "ВК" РЕДАКТОР ЗАПРАШИВАЕТ:

```
ОКНО ПЕРЕНОСИМОЕ (Д/Н)?
```

ЕСЛИ ОКНО ОПРЕДЕЛЯЕТСЯ КАК ТИП "Ф", ТО НА ЗАПРОС:

```
ВЫРАЖЕНИЕ?
```

С КЛАВИАТУРЫ ВВОДИТСЯ АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ, РЕЗУЛЬТАТ КОТОРОГО ПОМЕЩАЕТСЯ В ОКНО.

АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ ЗАДАЕТСЯ В ТРАДИЦИОННОЙ ФОРМЕ ЗАПИСИ (СКОБОЧНОЕ, ПРИОРИТЕТНОЕ).

АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ ДОПУСКАЕТ АРИФМЕТИЧЕСКИЕ ОПЕРАЦИИ "+", "-", "*", "/". ОПЕРАНДАМИ АРИФМЕТИЧЕСКОГО ВЫРАЖЕНИЯ ЯВЛЯЮТСЯ:

ЦЕЛЫЕ И ВЕЩЕСТВЕННЫЕ КОНСТАНТЫ, НАПРИМЕР:

```
1, 2, 3.45, 0.01
```

СТОЛБЕЦ, ЗАДАВАЕМЫЙ НОМЕРОМ, НАПРИМЕР:

```
#1, #3
```

ГДЕ # - ПРИЗНАК СТОЛБЦА. В АРИФМЕТИЧЕСКОМ ВЫРАЖЕНИИ ИСПОЛЬЗУЮТСЯ ТОЛЬКО ЧИСЛОВЫЕ ТИПЫ СТОЛБЦОВ;

ФУНКЦИИ НАД СТОЛБЦАМИ БАЗЫ ДАННЫХ.

АРГУМЕНТОМ ФУНКЦИИ ЯВЛЯЕТСЯ АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ. ДОПУСТИМЫ СЛЕДУЮЩИЕ ФУНКЦИИ:

**СУМ**

ФУНКЦИЯ СУММИРОВАНИЯ. ДЛЯ КАЖДОЙ АКТИВНОЙ ЗАПИСИ ВЫЧИСЛЯЕТ ЗНАЧЕНИЕ ЗАДАННОГО В КАЧЕСТВЕ АРГУМЕНТА ФУНКЦИИ ВЫРАЖЕНИЯ И ВЫПОЛНЯЕТ СУММИРОВАНИЕ ЭТИХ ЗНАЧЕНИЙ ПО ВСЕМ АКТИВНЫМ ЗАПИСЯМ. В ЧАСТНОМ СЛУЧАЕ ПОЗВОЛЯЕТ ВЫЧИСЛИТЬ СУММУ ЗНАЧЕНИЙ СТОЛБЦА, НАПРИМЕР:

```
СУМ(#1), СУМ(#1+#2)
```

ФУНКЦИЯ ВЫЧИСЛЕНИЯ СРЕДНЕГО. ДЛЯ КАЖДОЙ АКТИВНОЙ ЗАПИСИ ВЫЧИСЛЯЕТ ЗНАЧЕНИЕ ЗАДАННОГО В КАЧЕСТВЕ АРГУМЕНТА ФУНКЦИИ ВЫРАЖЕНИЯ И ВЫЧИСЛЯЕТ СРЕДНЕЕ ОТ ЭТИХ ЗНАЧЕНИЙ, НАПРИМЕР:

```

```

ФУНКЦИЯ ВЫЧИСЛЕНИЯ МИНИМУМА. ДЛЯ КАЖДОЙ АКТИВНОЙ ЗАПИСИ ВЫЧИСЛЯЕТ ЗНАЧЕНИЕ ЗАДАННОГО В КАЧЕСТВЕ АРГУМЕНТА ФУНКЦИИ ВЫРАЖЕНИЯ И НАХОДИТ МИНИМАЛЬНОЕ ЗНАЧЕНИЕ СРЕДИ ЭТИХ ЗНАЧЕНИЙ, НАПРИМЕР:

```
МИН(#3)
```

**МАК**

ФУНКЦИЯ ВЫЧИСЛЕНИЯ МАКСИМУМА. ДЛЯ КАЖДОЙ АКТИВНОЙ ЗАПИСИ ВЫЧИСЛЯЕТ ЗНАЧЕНИЕ ЗАДАННОГО В КАЧЕСТВЕ АРГУМЕНТА ФУНКЦИИ ВЫРАЖЕНИЯ И НАХОДИТ МАКСИМАЛЬНОЕ ЗНАЧЕНИЕ СРЕДИ ЭТИХ ЗНАЧЕНИЙ;

**ЧАЗ**

ФУНКЦИЯ ВЫЧИСЛЕНИЯ ЧИСЛА АКТИВНЫХ ЗАПИСЕЙ,

НАПРИМЕР:

ОНА ПРИМЕТ ЗНАЧЕНИЕ 10.

```
(1+#2-3*5.4)/6
```

СПЕЦИАЛЬНАЯ ОПЕРАЦИЯ "-" ПРИСВАИВАЕТ ЗНАЧЕНИЕ ВЫРАЖЕНИЯ, СТОЯЩЕГО СПРАВА ОТ ЗНАКА ОПЕРАЦИИ, СТОЛБЦУ ТЕКУЩЕЙ ЗАПИСИ, НОМЕР КОТОРОГО УКАЗАН СЛЕВА ОТ ЗНАКА ОПЕРАЦИИ (ОПЕРАЦИЯ "-" ИСПОЛЬЗУЕТСЯ ТОЛЬКО ДЛЯ ПРОГРАММЫ ПОИСКА RETRDB).

ЕСЛИ ВЫРАЖЕНИЕ СОДЕРЖИТ ОШИБКИ, ТО НА ЭКРАН ВЫДАЕТСЯ ДИАГНОСТИЧЕСКОЕ СООБЩЕНИЕ И ПОВТОРЯЕТСЯ ЗАПРОС НА ВВОД ВЫРАЖЕНИЯ.

```
ВЫРАЖЕНИЕ? #2*0.5+#3

```

ЕСЛИ РЕЗУЛЬТАТ ВЫЧИСЛЕНИЙ ИМЕЕТ ВЕЩЕСТВЕННЫЙ ТИП, ТО ЗАПРАШИВАЕСЯ ФОРМА ВЫВОДА РЕЗУЛЬТАТА, КАК И В СЛУЧАЕ ОПРЕДЕЛЕНИЯ ОКНА ТИПА "Б".

## Приложение. ДИАГНОСТИЧЕСКИЕ СООБЩЕНИЯ ПРОГРАММЫ

**"ВХОДНОЙ ФАЙЛ НЕ НАЙДЕН"**

НЕВЕРНОЕ ЗАДАНИЕ ИМЕНИ ВХОДНОГО ФАЙЛА ИЛИ ЕГО ОТСУТСТВИЕ НА УКАЗАННОМ УСТРОЙСТВЕ. ДЕЙСТВИЕ: ПРАВИЛЬНО УКАЗАТЬ ИМЯ ВХОДНОГО ФАЙЛА ЛИБО ЗАМЕНИТЬ ВНЕШНИЙ НОСИТЕЛЬ.

**"НЕВЕРНЫЙ КЛЮЧ"**

ЗАДАН КЛЮЧ, ОТЛИЧНЫЙ ОТ /R. ЗАДАЕТСЯ В ИМЕНИ ВХОДНОГО ФАЙЛА ПРИ ОТСУТСТВИИ НА ТЕРМИНАЛЕ АППАРАТНОГО СДВИГА ЭКРАНА НА 1 СТРОКУ ВНИЗ. ДЕЙСТВИЕ: УКАЗАТЬ КЛЮЧ /R ПРИ ИМЕНИ ВХОДНОГО ФАЙЛА.

**"ШИРИНА ДОКУМЕНТА ПРЕВЫШАЕТ 156 СИМВОЛОВ"**

ЗАДАННАЯ ШИРИНА ДОКУМЕНТА БОЛЬШЕ 156 СИМВОЛОВ. ДЕЙСТВИЕ: ЗАДАТЬ ДОПУСТИМУЮ ШИРИНУ ДОКУМЕНТА.

**БАЗА ДАННЫХ НЕ НАЙДЕНА.**
