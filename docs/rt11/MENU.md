## АННОТАЦИЯ

ПРОГРАММА ПЕЧАТИ МЕНЮ.

# СТРУКТУРА МЕНЮ

МЕНЮ ПРЕДСТАВЛЯЕТ СОБОЙ ПЕРЕЧЕНЬ НЕКОТОРЫХ РАБОТ ПОД ОБЩИМ ЗАГОЛОВКОМ. ЗАГОЛОВКОМ МЕНЮ ЯВЛЯЕТСЯ ПРОИЗВОЛЬНАЯ ТЕКСТОВАЯ СТРОКА.

В ОДНОМ МЕНЮ МОЖЕТ СОДЕРЖАТЬСЯ НЕ БОЛЕЕ 18 РАБОТ. МЕНЮ ХРАНИТСЯ В ФАЙЛЕ С РАСШИРЕНИЕМ .MEN, НАЗЫВАЕМОМ ФАЙЛОМ МЕНЮ.

РАБОТА В МЕНЮ ПРЕДСТАВЛЯЕТСЯ КАК НАБОР СОСТАВЛЯЮЩИХ КОМПОНЕНТОВ, ОПРЕДЕЛЯЮЩИХ ЕЕ НАЗВАНИЕ И ДЕЙСТВИЯ ПРИ ВЫПОЛНЕНИИ. КОМПОНЕНТЫ РАЗДЕЛЯЮТСЯ НА ОБЩИЕ И СПЕЦИФИЧЕСКИЕ. ОБЩИМИ КОМПОНЕНТАМИ ЯВЛЯЮТСЯ:

ИМЯ РАБОТЫ;

ТИП РАБОТЫ.

ИМЕНЕМ РАБОТЫ ЯВЛЯЕТСЯ ПРОИЗВОЛЬНАЯ ТЕКСТОВАЯ СТРОКА. ТИПОМ РАБОТЫ ОПРЕДЕЛЯЕТСЯ СПОСОБ ЕЕ ВЫПОЛНЕНИЯ. ИМЕЮТСЯ ТРИ ТИПА РАБОТ:

КОМАНДЫ МОНИТОРА;

СПРАВКА;

МЕНЮ.

## РАБОТА ТИПА "КОМАНДЫ МОНИТОРА"

СПЕЦИФИЧЕСКИМИ КОМПОНЕНТАМИ РАБОТЫ ЯВЛЯЮТСЯ:

```
СПОСОБ ВОЗВРАТА В МЕНЮ;
КОМАНДЫ МОНИТОРА;
ФОРМАЛЬНЫЕ ПАРАМЕТРЫ;
СПРАВКА О РАБОТЕ.
```

ПРИ ВЫПОЛНЕНИИ РАБОТЫ ДАННОГО ТИПА ОТРАБАТЫВАЕТСЯ НАБОР КОМАНД, АНАЛОГИЧНЫЙ КОМАНДНОМУ ФАЙЛУ, ПО ЗАВЕРШЕНИЮ ВЫПОЛНЕНИЯ КОТОРОГО ПРОИСХОДИТ ВОЗВРАТ В МЕНЮ. ВОЗВРАТ В МЕНЮ ПРОИСХОДИТ ЛИБО БЕЗУСЛОВНО, АВТОМАТИЧЕСКИ, ЛИБО ПО НАЖАТИЮ КЛАВИШИ "ВК". В ПОСЛЕДНЕМ СЛУЧАЕ РЕЗУЛЬТАТ ВЫПОЛНЕННОЙ РАБОТЫ НЕ СТИРАЕТСЯ С ЭКРАНА, ПОКА НЕ БУДЕТ НАЖАТА КЛАВИША "ВК". ТАКОЙ СПОСОБ ВОЗВРАТА ПОЛЕЗНО (А ЧАСТО НЕОБХОДИМО) ЗАДАВАТЬ, ЕСЛИ ДАННАЯ РАБОТА ОСУЩЕСТВЛЯЕТ ВЫВОД НА ЭКРАН СПРАВОЧНОЙ ИНФОРМАЦИИ, КОТОРУЮ НУЖНО ПРОСМОТРЕТЬ. НАПРИМЕР, ВЫВОД НА ЭКРАН КАТАЛОГА УСТРОЙСТВА, ИНФОРМАЦИИ ПО КОНФИГУРАЦИИ СИСТЕМЫ, ПОДСКАЗКИ ПО КОМАНДЕ МОНИТОРА И T.П.. СПОСОБ ВОЗВРАТА В МЕНЮ УКАЗЫВАЕТСЯ ПРИ СОЗДАНИИ ИЛИ РЕДАКТИРОВАНИИ РАБОТЫ.

КОМАНДЫ МОНИТОРА В МЕНЮ ЗАДАЮТСЯ АНАЛОГИЧНО КОМАНДНОМУ ФАЙЛУ. ВСЕ СОГЛАШЕНИЯ, ОГРАНИЧЕНИЯ, МЕХАНИЗМ ВЫПОЛНЕНИЯ ТАКИЕ ЖЕ, КАК И ДЛЯ КОМАНДНОГО ФАЙЛА. В ЧАСТНОСТИ, ВЫЗОВ ПРОГРАММЫ В НАБОРЕ КОМАНД МОНИТОРА ИМЕЕТ СЛЕДУЮЩУЮ ОСОБЕННОСТЬ. ЕСЛИ ПРОГРАММА ПО ЗАВЕРШЕНИЮ ОБРАБОТКИ ДАННЫХ ПРОИЗВОДИТ ПОВТОРНЫЙ (ЦИКЛИЧЕСКИЙ) ЗАПРОС СПЕЦИФИКАЦИЙ, ТО ДЛЯ ВЫХОДА ИЗ НЕЕ В КАЧЕСТВЕ КОМАНДНОЙ СТРОКИ НУЖНО ЗАДАТЬ СТРОКУ СИМВОЛОВ "^C", ИММИТИРУЮЩУЮ ОДНОВРЕМЕННОЕ НАЖАТИЕ КЛАВИШ "CTRL" И "C". (CTRL/C). НАПРИМЕР

```

DK:/F/K

```

КОМАНДЫ МОНИТОРА МОГУТ ИМЕТЬ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ. ФОРМАЛЬНЫЙ ПАРАМЕТР ЗАДАЕТСЯ НОМЕРОМ (ЦИФРОЙ ОТ 0 ДО 9), ПЕРЕД КОТОРЫМ СТОИТ СИМВОЛ "&". КАЖДЫЙ ФОРМАЛЬНЫЙ ПАРАМЕТР ДОЛЖЕН БЫТЬ ОПИСАН, T.E. КАЖДОМУ НОМЕРУ ФОРМАЛЬНОГО ПАРАМЕТРА ДОЛЖЕН БЫТЬ ПОСТАВЛЕН В СООТВЕТСТВИЕ ТЕКСТ ЗАПРОСА.

ФАКТИЧЕСКИЕ ЗНАЧЕНИЯ ФОРМАЛЬНЫМ ПАРАМЕТРАМ ПРИСВАИВАЮТСЯ ВО ВРЕМЯ ВЫПОЛНЕНИЯ РАБОТЫ ПО ЗАПРОСАМ, ИМЕНУЮЩИМ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ.

ЯЗЫК ОПИСАНИЯ ФОРМАЛЬНЫХ ПАРАМЕТРОВ И ПРИМЕРЫ РАБОТ ТИПА "КОМАНДЫ МОНИТОРА" ПРИВЕДЕНЫ В РАЗДЕЛЕ 3.

КОМПОНЕНТ "СПРАВКА О РАБОТЕ" СОДЕРЖИТ ИМЯ ТЕКСТОВОГО ФАЙЛА, СОДЕРЖАЩЕГО СПРАВКУ О ТЕКУЩЕЙ РАБОТЕ. ПРИ ВЫПОЛНЕНИИ РАБОТЫ ПО НАЖАТИЮ КЛАВИШИ "?" СПРАВКА В РЕЖИМЕ ЛИСТАНИЯ ВЫВОДИТСЯ НА ЭКРАН (СМ. ПОДРАЗД. 1.2). ЗАДАНИЕ ФАЙЛА СПРАВКИ В РАБОТЕ ТИПА "КОМАНДЫ МОНИТОРА" НЕ ЯВЛЯЕТСЯ ОБЯЗАТЕЛЬНЫМ. ПРИ ОТСУТСТВИИ СПРАВКИ КЛАВИША "?" НЕ ОТРАБАТЫВАЕТСЯ.

## РАБОТА ТИПА "СПРАВКА"

СПЕЦИФИЧЕСКИМ КОМПОНЕНТОМ РАБОТЫ ТИПА "СПРАВКА" ЯВЛЯЕТСЯ ИМЯ ТЕКСТОВОГО ФАЙЛА, СОДЕРЖАЩЕГО СПРАВКУ. ПРИ ВЫПОЛНЕНИИ ДАННОЙ РАБОТЫ ФАЙЛ СПРАВКИ ВЫВОДИТСЯ НА ЭКРАН ДЛЯ ПРОСМОТРА. ПРОСМОТР ОСУЩЕСТВЛЯЕТСЯ В РЕЖИМЕ ЛИСТАНИЯ КАК В ПРЯМОМ, ТАК И В ОБРАТНОМ ПОРЯДКЕ. РАЗМЕР ЛИСТА РАВЕН РАЗМЕРУ ЭКРАНА (24 СТРОКИ). ДЛЯ ПРОСМОТРА СПРАВКИ ИСПОЛЬЗУЮТСЯ СЛЕДУЮЩИЕ ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ:

```
"СТРЕЛКА ВНИЗ" - ВЫВОД СЛЕДУЮЩЕГО ЛИСТА СПРАВКИ;
"СТРЕЛКА ВВЕРХ" - ВЫВОД ПРЕДЫДУЩЕГО ЛИСТА СПРАВКИ;
"В НАЧАЛО ТЕКСТА" - ВЫВОД ПЕРВОГО ЛИСТА СПРАВКИ;
"В КОНЕЦ ТЕКСТА"  - ВЫВОД ПОСЛЕДНЕГО ЛИСТА СПРАВКИ
```

ВОЗВРАТ В МЕНЮ ОСУЩЕСТВЛЯЕТСЯ ПО НАЖАТИЮ КЛАВИШИ "ВК".

ПО УМОЛЧАНИЮ ФАЙЛ СПРАВКИ ИМЕЕТ РАСШИРЕНИЕ "QUE".

МАКСИМАЛЬНО ДОПУСТИМЫЙ РАЗМЕР ФАЙЛА СПРАВКИ ЗАВИСИТ ОТ ТИПА МОНИТОРА, ОБ'ЕМА РЕЗИДЕНТНЫХ USR И ДРАЙВЕРОВ. КОМПОНЕНТ "ИМЯ ФАЙЛА" УКАЗЫВАЕТ НА ФАЙЛ, СОДЕРЖАЩИЙ МЕНЮ. ПРИ ВЫПОЛНЕНИИИ ЭТОЙ РАБОТЫ ОСУЩЕСТВЛЯЕТСЯ ПЕРЕХОД НА МЕНЮ СЛЕДУЮЩЕГО УРОВНЯ. ТАКИМ ОБРАЗОМ, РАБОТА ДАННОГО ТИПА СЛУЖИТ ДЛЯ ПОДДЕРЖКИ ИЕРАРХИЧЕСКОЙ СТРУКТУРЫ МЕНЮ.

КОМПОНЕНТ "СПРАВКА О РАБОТЕ" АНАЛОГИЧЕН ТАКОМУ ЖЕ КОМПОНЕНТУ В РАБОТЕ ТИПА "КОМАНДЫ МОНИТОРА" (СМ. ПОДРАЗД. 1.1).

# СТАРТОВАЯ РАБОТА

МЕНЮ МОЖЕТ СОДЕРЖАТЬ СТАРТОВУЮ РАБОТУ, БЕЗУСЛОВНО ВЫПОЛНЯЮЩУЮСЯ ПРИ ПЕРВОМ ОБРАЩЕНИИ К НЕМУ. ОНА МОЖЕТ БЫТЬ ОДНОГО ИЗ ДВУХ ТИПОВ:

КОМАНДЫ МОНИТОРА;

СПРАВКА.

СТАРТОВАЯ РАБОТА НЕ ИМЕЕТ НАЗВАНИЯ, НА ЭКРАНЕ НЕ ОТОБРАЖАЕТСЯ И НЕ ВХОДИТ В ОБЩЕЕ КОЛИЧЕСТВО РАБОТ МЕНЮ. В ОСТАЛЬНОМ МЕХАНИЗМ ЕЕ РЕДАКТИРОВАНИЯ И ВЫПОЛЕНИЯ НЕ ОТЛИЧАЮТСЯ ОТ ОБЫЧНОЙ РАБОТЫ МЕНЮ.

# ЛОГИЧЕСКИЕ УСТРОЙСТВА СИСТЕМЫ МЕНЮ

ПРИ РАБОТЕ СИСТЕМЫ МЕНЮ ИСПОЛЬЗУЮТСЯ ЛОГИЧЕСКИЕ УСТРОЙСТВА, КОТОРЫЕ ПОЛЬЗОВАТЕЛЬ ДОЛЖЕН НАЗНАЧИТЬ ПЕРЕД НАЧАЛОМ РАБОТЫ С МЕНЮ: M, STK, SRV.

**M**

УСТРОЙСТВО, НА КОТОРОМ НАХОДИТСЯ ИНТЕРПРЕТАТОР МЕНЮ INTMEN.SAV И, ЖЕЛАТЕЛЬНО, РЕДАКТОР МЕНЮ EDIMEN.SAV;

**SRV**

УСТРОЙСТВО, СОДЕРЖАЩЕЕ ФАЙЛ МЕНЮ СО СТАНДАРТНЫМ ИМЕНЕМ SRV:SRVMEN.MEN, НАЗЫВАЕМОЕ СЕРВИСНЫМ;

**STK**

УСТРОЙСТВО, НА КОТОРОЕ В ПРОЦЕССЕ ВЫПОЛНЕНИЯ МЕНЮ ЗАПИСЫВАЮТСЯ ВРЕМЕННЫЕ РАБОЧИЕ ФАЙЛЫ. ЭТИ ФАЙЛЫ СОЗДАЮТСЯ ИНТЕРПРЕТАТОРОМ МЕНЮ.

# ЗАЩИТА МЕНЮ ПАРОЛЕМ

МЕНЮ МОЖЕТ БЫТЬ ЗАЩИЩЕНО ПАРОЛЕМ. ПАРОЛЬ СОДЕРЖИТ ОТ 1 ДО 4 СИМВОЛОВ. ПАРОЛЬ, СОСТОЯЩИЙ ИЗ ОДНИХ ПРОБЕЛОВ, РАССМАТРИВАЕТСЯ КАК ОТСУТСТВИЕ ПАРОЛЯ. ПАРОЛЬ ВВОДИТСЯ И РЕДАКТИРУЕТСЯ ПРИ СОЗДАНИИ ИЛИ ПРИ РЕДАКТИРОВАНИИ МЕНЮ.

ЕСЛИ МЕНЮ ЗАЩИЩЕНО ПАРОЛЕМ, ТО ЛЮБОЙ РАБОТЕ С НИМ ПРЕДШЕСТВУЕТ ВВОД ПАРОЛЯ.

ПРИ ВЫЗОВЕ ПРОГРАММЫ РАБОТЫ С МЕНЮ (РЕДАКТОРА, ПРОГРАММЫ ПЕЧАТИ ИЛИ ИНТЕРПРЕТАТОРА) ВЫДАЕТСЯ ЗАПРОС:

```
ПАРОЛЬ?
```

ЕСЛИ ПАРОЛЬ ВВОДИТСЯ НЕВЕРНО, ВЫДАЕТСЯ ДИАГНОСТИЧЕСКОЕ СООБЩЕНИЕ:

```
НЕВЕРНЫЙ ПАРОЛЬ
```

И ПАРОЛЬ ЗАПРАШИВАЕТСЯ ПОВТОРНО. ЕСЛИ И ВТОРИЧНО ПАРОЛЬ ВВОДИТСЯ НЕВЕРНО, ПОВТОРЯЕТСЯ ВЫВОД ДИАГНОСТИЧЕСКОГО СООБЩЕНИЯ И ПРОИСХОДИТ ВЫХОД ИЗ МЕНЮ ТЕКУЩЕГО УРОВНЯ.

ПРИ ВВОДЕ ПАРОЛЯ С КЛАВИАТУРЫ ДИСПЛЕЯ СИМВОЛЫ ПАРОЛЯ НА ЭКРАН НЕ ВЫВОДЯТСЯ.

ПРИ ОТСУТСТВИИ ПАРОЛЯ ДОСТУП К МЕНЮ ОСУЩЕСТВЛЯЕТСЯ НЕПОСРЕДСТВЕННО ПОСЛЕ ЗАДАНИЯ ЕГО ИМЕНИ.

# РЕДАКТОР МЕНЮ

РЕДАКТОР МЕНЮ ПРЕДНАЗНАЧЕН ДЛЯ СОЗДАНИЯ И РЕДАКТИРОВАНИЯ ФАЙЛОВ МЕНЮ.

ВЫЗОВ РЕДАКТОРА С СИСТЕМНОГО УСТРОЙСТВА ОСУЩЕСТВЛЯЕТСЯ КОМАНДОЙ:

```
        .R EDIMEN

С УСТРОЙСТВА М -

        .RU M:EDIMEN
```

РЕДАКТОР ЗАПРАШИВАЕТ ИМЯ ВХОДНОГО ФАЙЛА МЕНЮ:

```
ВХОДНОЙ ФАЙЛ МЕНЮ?
```

ЕСЛИ РАСШИРЕНИЕ НЕ УКАЗЫВАЕТСЯ, ТО ПО УМОЛЧАНИЮ БЕРЕТСЯ "MEN". ЕСЛИ ИМЯ ФАЙЛА НЕ УКАЗЫВАЕТСЯ - СОЗДАЕТСЯ НОВЫЙ ФАЙЛ. ПОСЛЕ ПРИВЯЗКИ ВХОДНОГО ФАЙЛА РЕДАКТОР ЗАПРАШИВАЕТ ИМЯ ВЫХОДНОГО ФАЙЛА:

```

```

## РЕДАКТИРОВАНИЕ МЕНЮ

ДЛЯ РЕДАКТИРОВАНИЯ ФАЙЛ МЕНЮ СЧИТЫВАЕТСЯ В БУФЕР.

РЕДАКТИРОВАНИЕ МЕНЮ РАБОТ ОСНОВАНО НА СОЧЕТАНИИ ДВУХ ПРИЕМОВ:

ВЕДЕНИЕ ДИАЛОГА ЧЕРЕЗ МЕНЮ;

ВВОД И РЕДАКТИРОВАНИЕ ТЕКСТА В ОКНЕ.

НА ЭКРАНЕ МЕНЮ ПРЕДСТАВЛЯЕТ СОБОЙ ПОСЛЕДОВАТЕЛЬНОСТЬ СТРОК ПОД ОБЩИМ ЗАГОЛОВКОМ. ПЕРЕД ОДНОЙ ИЗ СТРОК УСТАНОВЛЕН УКАЗАТЕЛЬ "->" (СТРЕЛКА), КОТОРЫЙ ПРИ ПОМОЩИ КЛАВИШ "СТРЕЛКА ВВЕРХ", "СТРЕЛКА ВНИЗ", "В НАЧАЛО ТЕКСТА", "В КОНЕЦ ТЕКСТА" МОЖНО ПЕРЕМЕЩАТЬ, ВЫБИРАЯ НУЖНУЮ СТРОКУ. ПРИ НАЖАТИИ КЛАВИШИ "СБРОС" ПРОИСХОДИТ ВЫХОД ИЗ МЕНЮ БЕЗ ВЫПОЛЕНИЯ КАКИХ-ЛИБО ДЕЙСТВИЙ. ПО НАЖАТИЮ КЛАВИШИ "ВК" ВЫПОЛНЯЕТСЯ ДЕЙСТВИЕ, УКАЗАННОЕ В СТРОКЕ, ГДЕ НАХОДИТСЯ УКАЗАТЕЛЬ. НА ВРЕМЯ ВЫПОЛЕНИЯ ЭТОГО ДЕЙСТВИЯ УКАЗАТЕЛЬ СТАНОВИТСЯ ПАССИВНЫМ И ОБОЗНАЧАЕТСЯ СИМВОЛОМ "+". ПАССИВНЫЙ УКАЗАТЕЛЬ ВДОЛЬ МЕНЮ НЕ ПЕРЕМЕЩАЕТСЯ.

СТРОКИ МЕНЮ МОГУТ БЫТЬ ПРОНУМЕРОВАНЫ. НОМЕРА СТРОК ОДНОСИМВОЛЬНЫЕ. ПЕРВЫЕ 9 СТРОК НУМЕРУЮТСЯ ЦИФРАМИ ОТ 0 ДО 9, ОСТАЛЬНЫЕ - ПРОПИСНЫМИ ЛАТИНСКИМИ БУКВАМИ В АЛФАВИТНОМ ПОРЯДКЕ, НАЧИНАЯ С БУКВЫ "А".

НОМЕРА СТРОК  МЕНЮ ЯВЛЯЮТСЯ ФУНКЦИОНАЛЬНЫМИ КЛАВИШАМИ. ПО НАЖАТИЮ ТАКОЙ КЛАВИШИ ВЫПОЛНЯЕТСЯ ДЕЙСТВИЕ СТРОКИ, НОМЕР КОТОРОЙ УКАЗАН НА ЭТОЙ КЛАВИШЕ. МОЖНО ОТКАЗАТЬСЯ ОТ НУМЕРАЦИИ. ДЛЯ ЭТОГО СУЩЕСТВУЕТ ФУНКЦИОНАЛЬНАЯ КЛАВИША "НУМЕРАЦИЯ", НАЖАТИЕ КОТОРОЙ ПОПЕРЕМЕННО ВКЛЮЧАЕТ И ВЫКЛЮЧАЕТ НУМЕРАЦИЮ СТРОК МЕНЮ. ПРИ ВЫКЛЮЧЕННЫХ НОМЕРАХ ИХ ДЕЙСТВИЕ КАК ФУНКЦИОНАЛЬНЫХ КЛАВИШ НЕ ОСУЩЕСТВЛЯЕТСЯ.

> ЕСЛИ НА УСТРОЙСТВЕ STK НАХОДИТСЯ ФАЙЛ STEKM.STK, ТО РЕДАКТОР МЕНЮ УСТАНАВЛИВАЕТ ТОТ РЕЖИМ НУМЕРАЦИИ, КОТОРЫЙ УКАЗАН В ЭТОМ ФАЙЛЕ. ЕСЛИ ЭТОТ ФАЙЛ ОТСУТСТВУЕТ, ТО СТРОКИ МЕНЮ ПРОНУМЕРОВАНЫ ПО УМОЛЧАНИЮ.

ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ УПРАВЛЕНИЯ МЕНЮ РЕДАКТОРА ОПИСАНЫ В ПРИЛОЖЕНИИ 1.

ОКНО (VII) - ДЛЯ ВВОДА И РЕДАКТИРОВАНИЯ СПЕЦИФИКАЦИИ ФАЙЛА СПРАВКИ ИЛИ МЕНЮ.

ОКНО (VIII) ПРЕЛНАЗНАЧЕНО ДЛЯ ВВОДА И РЕДАКТИРОВАНИЯ ИМЕНИ ФАЙЛА СПРАВКИ, ПРИВЯЗАННОЙ К ТЕКУЩЕЙ РАБОТЕ. ЭТО ОКНО ХАРАКТЕРНО ДЛЯ РАБОТ ТИПА "МЕНЮ" И "КОМАНДЫ МОНИТОРА".

РЕДАКТИРОВАНИЕ РАБОТЫ ПРОИЗВОДИТСЯ ЧЕРЕЗ МЕНЮ КОМПОНЕНТОВ РАБОТЫ. ЧТОБЫ ОТРЕДАКТИРОВАТЬ НУЖНЫЙ КОМПОНЕНТ РАБОТЫ, НУЖНО УСТАНОВИТЬ УКАЗАТЕЛЬ НА ЕЕ НАЗВАНИЕ В МЕНЮ КОМПОНЕНТОВ РАБОТЫ И, НАЖАВ КЛАВИШУ "ВК", ПЕРЕЙТИ К РЕДАКТИРОВАНИЮ ЭТОГО КОМПОНЕНТА. ПО ЗАВЕРШЕНИЮ РЕДАКТИРОВАНИЯ ПРОИСХОДИТ ВОЗВРАТ В МЕНЮ КОМПОНЕНТОВ.

ПРИ РЕДАКТИРОВАНИИ РАБОТЫ ТИПА "КОМАНДЫ МОНИТОРА" КОМПОНЕНТ "ФОРМАЛЬНЫЕ ПАРАМЕТРЫ" ПРИСУТСТВУЕТ ТОЛЬКО В ТОМ СЛУЧАЕ, ЕСЛИ КОМАНДЫ МОНИТОРА СОДЕРЖАТ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ.

ВВОД И РЕДАКТИРОВАНИЕ ИМЕНИ ФАЙЛА СПРАВКИ О РАБОТЕ ОСУЩЕСТВЛЯЕТСЯ В ОКНЕ (VIII). В СЛУЧАЕ РАБОТЫ ТИПА "КОМАНДЫ МОНИТОРА" ОКНО (VIII) НАКЛАДЫВАЕТСЯ НА ОКНО (VI).

РЕДАКТИРОВАНИЕ ИМЕНИ РАБОТЫ, КОМАНД МОНИТОРА, ФОРМАЛЬНЫХ ПАРАМЕТРОВ ИЛИ ИМЕНИ ФАЙЛА ОСУЩЕСТВЛЯЕТСЯ ТЕКСТОВЫМ ОКОННЫМ РЕДАКТОРОМ. РЕДАКТИРОВАНИЕ ТИПА РАБОТЫ ИЛИ СПОСОБА ВОЗВРАТА В МЕНЮ ОСУЩЕСТВЛЯЕТСЯ ПОСРЕДСТВОМ МЕНЮ, ВЫВЕДЕННОМ В ОКНЕ (II).

МЕНЮ ТИПА РАБОТЫ ИМЕЕТ ВИД:

```
     ТИП РАБОТЫ

-> 1 КОМАНДЫ МОНИТОРА
   2 СПРАВКА
   3 МЕНЮ
```

МЕНЮ СПОСОБА ВОЗВРАТА ИМЕЕТ ВИД:

```
     СПОСОБ ВОЗВРАТА В МЕНЮ

-> 1 БЕЗУСЛОВНЫЙ
   2 ПО НАЖАТИЮ "ВК"
```

ПРИ ИЗМЕНЕНИИ ТИПА РАБОТЫ ОСУЩЕСТВЛЯЕТСЯ ПЕРЕРАЗМЕТКА ЭКРАНА.

ПРИ СОЗДАНИИ ИЛИ РЕДАКТИРОВАНИИ РАБОТЫ ТИПА "КОМАНДЫ МОНИТОРА" ИМЕЕТСЯ ВОЗМОЖНОСТЬ СЧИТЫВАТЬ СОДЕРЖИМОЕ КОМАНДНЫХ ФАЙЛОВ В ОКНО КОМАНД МОНИТОРА. ДЛЯ ЭТОГО НУЖНО, НАХОДЯСЬ В ОКНЕ "КОМАНДЫ МОНИТОРА", НАЖАТЬ КЛАВИШУ "ПРЕДЫДУЩИЙ КАДР". В ОКНЕ ДИАГНОСТИКИ (III) ВЫДАЕТСЯ ЗАПРОС:

```
ИМЯ КОМАНДНОГО ФАЙЛА?
```

В ОТВЕТ НА КОТОРЫЙ НУЖНО ЗАДАТЬ ИМЯ КОМАНДНОГО ФАЙЛА. ЕСЛИ УКАЗАННЫЙ КОМАНДНЫЙ ФАЙЛ СУЩЕСТВУЕТ, ТО СОДЕРЖАЩИЙСЯ В НЕМ ТЕКСТ ДОПИСЫВАЕТСЯ В ОКНО "КОМАНДЫ МОНИТОРА", В ПРОТИВНОМ СЛУЧАЕ ВЫДАЕТСЯ СООБЩЕНИЕ:

```
КОМАНДНЫЙ ФАЙЛ НЕ НАЙДЕН
```

И ПО НАЖАТИЮ КЛАВИШИ "ВК" ПРОИСХОДИТ ВОЗВРАТ В ОКНО "КОМАНДЫ МОНИТОРА". ЧТОБЫ ВЕРНУТЬСЯ В ОКНО КОМАНД МОНИТОРА, НЕ НАБИРАЯ ИМЕНИ КОМАНДНОГО ФАЙЛА, НУЖНО НАЖАТЬ КЛАВИШУ "ВК".

ДЛЯ ЗАПИСИ РЕДАКТИРУЕМОЙ РАБОТЫ В МЕНЮ КОМПОНЕНТОВ РАБОТЫ ДОПОЛНИТЕЛЬНО ВВОДИТСЯ СТРОКА:

```
ЗАПИСЬ РАБОТЫ В МЕНЮ
```

ЭТА СТРОКА ПРИСУТСТВУЕТ ЛИШЬ В ТОМ СЛУЧАЕ, ЕСЛИ ВСЕ КОМПОНЕНТЫ РАБОТЫ ОПРЕДЕЛЕНЫ И ВСЕ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ ПРАВИЛЬНО ОПИСАНЫ. В ПРОТИВНОМ СЛУЧАЕ В ОКНЕ (III) ВЫДАЕТСЯ СООБЩЕНИЕ О ПРИЧИНЕ ОШИБКИ. ВОЗМОЖНЫ СЛЕДУЮЩИЕ СООБЩЕНИЯ:

**НЕВЕРНО ОПИСАН ФОРМАЛЬНЫЙ ПАРАМЕТР**

ЕСЛИ ДОПУЩЕНА ОШИБКА В СИНТАКСИСЕ ОПИСАНИЯ ФОРМАЛЬНОГО ПАРАМЕТРА;

**ОПИШИТЕ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ**

ЕСЛИ ХОТЯ БЫ ОДИН ФОРМАЛЬНЫЙ ПАРАМЕТР НЕ ОПИСАН;

**НЕДОПУСТИМЫЙ ПЕРЕНОС**

ЕСЛИ НЕВЕРНО ОФОРМЛЕН ПЕРЕНОС ПРИ ОПИСАНИИ АЛЬТЕРНАТИВНОГО ФОРМАЛЬНОГО ПАРАМЕТРА;

**ОШИБКА ЗАПРОСА ФОРМАЛЬНОГО ПАРАМЕТРА**

ЕСЛИ ДОПУЩЕНА ОШИБКА В ФОРМАТЕ ЗНАЧЕНИЯ, ИЛИ СТРОКА ПОДВОПРОСА АЛЬТЕРНАТИВНОГО ПАРАМЕТРА ЯВЛЯЕТСЯ ПУСТОЙ;

**НЕДОПУСТИМОЕ КОЛИЧЕСТВО АЛЬТЕРНАТИВ**

ЕСЛИ КОЛИЧЕСТВО АЛЬТЕРАНТИВ ФОРМАЛЬНОГО ПАРАМЕТРА ПРЕВЫШАЕТ МАКСИМАЛЬНО ДОПУСТИМОЕ - 22.

ВЫХОД ИЗ РЕЖИМА РЕДАКТИРОВАНИЯ РАБОТЫ БЕЗ ЗАПИСИ ОСУЩЕСТВЛЯЕТСЯ ПО НАЖАТИЮ КЛАВИШИ "СБРОС" В МЕНЮ КОМПОНЕНТОВ РАБОТЫ. В ЭТОМ СЛУЧАЕ РЕДАКТИРУЕМАЯ РАБОТА СОХРАНЯЕТСЯ В ПРЕЖНЕМ ВИДЕ.

### ВВОД РАБОТЫ

НОВАЯ РАБОТА В МЕНЮ ВВОДИТСЯ В ТОМ МЕСТЕ, НА КОТОРОЕ УКАЗЫВАЕТ СТРЕЛКА. РАБОТЫ, РАСПОЛОЖЕННЫЕ НИЖЕ СТРЕЛКИ СДВИГАЮТСЯ НА СТРОКУ ВНИЗ.

ДЛЯ ВВОДА РАБОТЫ В МЕНЮ НЕОБХОДИМО ПОДВЕСТИ СТРЕЛКУ К НУЖНОМУ МЕСТУ ВВОДА И ВЫЗВАТЬ МЕНЮ ФУНКЦИЙ РЕДАКТОРА. ЗАТЕМ УСТАНОВИТЬ СТРЕЛКУ НАПРОТИВ СТРОКИ:

```
ВВОД РАБОТЫ
```

И ПО НАЖАТИЮ КЛАВИШИ "ВК" ПЕРЕЙТИ К ВВОДУ РАБОТЫ. ПРИ ЭТОМ ЭКРАН ГАСНЕТ. НА НЕМ ПОЯВЛЯЕТСЯ ПУСТОЕ ОКНО (IV) ДЛЯ ВВОДА ИМЕНИ РАБОТЫ. МАРКЕР УСТАНАВЛИВАЕТСЯ В НАЧАЛЕ ОКНА. ПОСЛЕ ВВОДА ИМЕНИ РАБОТЫ НА ЭКРАНЕ ПОЯВЛЯЮТСЯ ОКНА (II) И (III) С МЕНЮ ТИПА РАБОТЫ В ОКНЕ (II).

ЕСЛИ ВЫБРАН ТИП РАБОТЫ "КОМАНДЫ МОНИТОРА", ТО В ОКНЕ (II) ЗАТЕМ ПОЯВЛЯЕТСЯ МЕНЮ СПОСОБА ВОЗВРАТА, ПОСЛЕ ВЫХОДА ИЗ НЕГО В ЭТОМ ОКНЕ ВЫДАЕТСЯ СПРАВОЧНАЯ ИНФОРМАЦИЯ О ТИПЕ РАБОТЫ И СПОСОБЕ ВОЗВРАТА В МЕНЮ. ЗАТЕМ ПОЯВЛЯЕТСЯ ОКНО (V) ДЛЯ ВВОДА КОМАНД МОНИТОРА. ЕСЛИ КОМАНДЫ МОНИТОРА СОДЕРЖАТ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ, ТО ПОСЛЕ ЗАВЕРШЕНИЯ ИХ ВВОДА НА ЭКРАНЕ ПОЯВЛЯЕТСЯ ОКНО (VI) ДЛЯ ВВОДА ОПИСАНИЙ ФОРМАЛЬНЫХ ПАРАМЕТРОВ.

ПОСЛЕ ЗАВЕРШЕНИЯ ВВОДА ОПИСАНИЙ ФОРМАЛЬНЫХ ПАРАМЕТРОВ ИЛИ КОМАНД МОНИТОРА, НЕ СОДЕРЖАЩИХ ФОРМАЛЬНЫЕ ПАРАМЕТРЫ, В ОКНЕ (I) ПОЯВЛЯЕТСЯ МЕНЮ КОМПОНЕНТОВ РАБОТЫ И ДАЛЬНЕЙШИЕ ДЕЙСТВИЯ ОПИСАНЫ В П.6.1.1.

ЕСЛИ ПРИ ВВОДЕ РАБОТЫ ВЫБРАН ТИП "СПРАВКА", ТО НА ЭКРАНЕ ПОЯВЛЯЕТСЯ ОКНО (VII) ДЛЯ ВВОДА ИМЕНИ ФАЙЛА СПРАВКИ, ПОСЛЕ ЧЕГО В ОКНЕ (I) ВЫДАЕТСЯ МЕНЮ КОМПОНЕНТОВ РАБОТЫ.

РАБОТА ТИПА "МЕНЮ" ВВОДИТСЯ АНАЛОГИЧНО РАБОТЕ ТИПА "СПРАВКА", ОДНАКО В МЕНЮ КОМПОНЕНТОВ ПОЯВЛЯЕТСЯ СТРОКА "СПРАВКА О РАБОТЕ", ПОЗВОЛЯЮЩАЯ В СПЕЦИАЛЬНОМ ОКНЕ ВВОДИТЬ ИМЯ СПРАВКИ, ОТНОСЯЩЕЙСЯ К ТЕКУЩЕЙ РАБОТЕ. ЕСЛИ ИМЯ ФАЙЛА СПРАВКИ НЕ НАЙДЕНО, ТО ОКНО СПРАВКИ НА ЭКРАН НЕ ВЫСВЕЧИВАЕТСЯ.

ЗАВЕРШАЕТСЯ ПРОЦЕСС ВВОДА РАБОТЫ ЗАПИСЬЮ ЕЕ В МЕНЮ ЧЕРЕЗ МЕНЮ КОМПОНЕНТОВ РАБОТЫ.


ЗАВЕРШАЮЩЕГОСЯ НАЖАТИЕМ КЛАВИШИ "ВК", НА ЭКРАН ВЫДАЕТСЯ "ПУСТОЕ" МЕНЮ РАБОТ, СОДЕРЖАЩЕЕ ЗАГОЛОВОК И ЕДИНСТВЕННУЮ ПУСТУЮ СТРОКУ В СПИСКЕ РАБОТ. ПО НАЖАТИЮ КЛАВИШИ "ВК" ВЫЗЫВАЕТСЯ МЕНЮ ФУНКЦИЙ РЕДАКТОРА И ДАЛЬНЕЙШИЕ ДЕЙСТВИЯ ЯВЛЯЮТСЯ ДЕЙСТВИЯМИ ПО РЕДАКТИРОВАНИЮ МЕНЮ, ОПИСАННЫЕ В ПОДРАЗД. 6.1.

# ПЕЧАТЬ МЕНЮ

ПРОГРАММА ПЕЧАТИ ПРЕДНАЗНАЧЕНА ДЛЯ ВЫДАЧИ НА ПЕЧАТЬ ИЛИ ДРУГОЕ УСТРОЙСТВО ВЫВОДА ФАЙЛА МЕНЮ В НАГЛЯДНОМ ВИДЕ.

ЗАПУСК ПРОГРАММЫ С СИСТЕМНОГО УСТРОЙСТВА ОСУЩЕСТВЛЯЕТСЯ КОМАНДОЙ

```
.R PRIMEN
```

НА ЭКРАН ВЫВОДИТСЯ ЗАПРОС:

```
ИМЯ ФАЙЛА МЕНЮ?
```

В ОТВЕТ НА КОТОРЫЙ НУЖНО ВВЕСТИ ИМЯ ФАЙЛА МЕНЮ. ЕСЛИ В ОТВЕТ НА ДАННЫЙ ЗАПРОС НАЖАТЬ КЛАВИШУ "ВК", ТО ВЫДАЕТСЯ НОМЕР ВЕРСИИ ПРОГРАММЫ И ЗАПРОС ПОВТОРЯЕТСЯ. ЕСЛИ УКАЗАННЫЙ ФАЙЛ НЕ НАЙДЕН, ТО НА ЭКРАН ВЫВОДИТСЯ СООБЩЕНИЕ:

```
НЕ НАЙДЕН ФАЙЛ МЕНЮ
```

И ЗАПРОС ИМЕНИ ФАЙЛА МЕНЮ ПОВТОРЯЕТСЯ. ЕСЛИ ФАЙЛ СУЩЕСТВУЕТ, ТО НА ЭКРАН ВЫДАЕТСЯ ЗАПРОС:

```
ИМЯ ФАЙЛА ПЕЧАТИ?
```

ПО УМОЛЧАНИЮ МЕНЮ ЗАПИСЫВАЕТСЯ НА ДИСК В ФАЙЛ С ИМЕНЕМ ВХОДНОГО ФАЙЛА МЕНЮ И С РАСШИРЕНИЕМ "LST".

ПОСЛЕ УКАЗАНИЯ ПАРОЛЯ (ЕСЛИ ОН ЕСТЬ) МЕНЮ ВЫВОДИТСЯ НА ЗАДАННОЕ УСТРОЙСТВО.

В ПРОГРАММЕ ПЕЧАТИ МЕНЮ ИМЕЕТСЯ КЛЮЧ /D ДЛЯ СОКРАЩЕННОЙ ПЕЧАТИ МЕНЮ. ПРИ ЭТОМ В ФАЙЛ ПЕЧАТИ ВЫВОДИТСЯ ТОЛЬКО НАЗВАНИЕ МЕНЮ И СПИСОК ИМЕН РАБОТ. КЛЮЧ НУЖНО ЗАДАВАТЬ ПРИ УКАЗАНИИ ИМЕНИ ФАЙЛА МЕНЮ.

# ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ

В ПРИЛОЖЕНИЯХ ПЕРЕЧИСЛЕНЫ ФУНКЦИОНАЛЬНЫЕ КЛАВИШИ, НАБИРАЕМЫЕ ПРИ ОДНОВРЕМЕННОМ НАЖАТИИ КЛАВИШИ "CTRL" И СООТВЕТСТВУЮЩЕЙ СИМВОЛЬНОЙ КЛАВИШИ (CTRL-КОМБИНАЦИИ). ЭТИ КЛАВИШИ ЯВЛЯЮТСЯ ОБЩИМИ ДЛЯ ВСЕХ ТИПОВ ТЕРМИНАЛОВ, НА КОТОРЫХ КОРРЕКТНО РАБОТАЕТ СИСТЕМА МЕНЮ. СООТВЕТСТВИЕ МНЕМОНИЧЕСКИХ ФУНКЦИОНАЛЬНЫХ КЛАВИШ CTRL-КОМБИНАЦИЯМ ДЛЯ КОНКРЕТНЫХ ТИПОВ ДИСПЛЕЕВ ПРИВЕДЕНЫ В ДОКУМЕНТЕ "УНИФИЦИРОВАННЫЕ УПРАВЛЯЮЩИЕ КЛАВИШИ КОМПЛЕКСА РТК МИКРО".
