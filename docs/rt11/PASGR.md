                          1. Графические процедуры
 
        Модуль Paslib.obj необходимо при операции LINK располагать сразу  за
   главным модулем и раньше  других  модулей  программы  и  библиотек.  Это
   вызвано тем, что виртуальный адресный  интервал  экранной  памяти  равен
   040000 - 0100000, и необходимо чтобы он не совпал с адресами графических
   функции.
 



 
        1.1. Procedure InitGraph(mode:integer) - установка режима дисплея.
 
        Способ использования:
 
                       InitGraph( mode );
 
        Процедура устанавливает режим графического дисплея:
 
              mode = 0    цветной графический режим 320х200 пикселов,
                          цветной текстовый режим   40х25 символов.
 
              mode = 1    монохромный графич. режим 640х200 пикселов,
                          монохромный текст.  режим 80х25 символов.
        Процедура кроме  установки  режима  дисплея,  устанавливает  нулевые
   координаты пикселов и стирает предыдущее изображение.
 

        1.2. Procedure SetColor(C:integer); - установка цвета изображения.
 
        Способ использования:

                         SetColor(c);
 
        Процедура устанавливает цвет пикселов для других графических функций.
   Значащими являются младшие три бита переменной c.
 
 
        1.3. Procedure SetFon(C:integer); - установка цвета фона.
 
        Способ использования:
 
                        SetFon(c);
 
        Процедура устанавливает цвет фона  для  других  графических  функций.
   Значащими являются младшие три бита переменной c.
 
 
        1.4. Procedure SetBorder(C:integer) - установка цвета

        Способ использования:

        Процедура устанавливает цвет окаймления экрана  в  цветном  режиме  и

       1.9. Procedure SetPixel(x,y:Integer); - установка пиксела изображения.

       1.12. procedure LineTo(x,y,mode:Integer); - рисование линии.
 
        Способ использования:

                         LineTo(x,y,mode);
 
        Процедура  рисует  линию  ранее  установленным   цветом,   от  
      текущих координат графического курсора  до координат  x, y.
        Если  mode = 1, то линия рисуется, 
              mode = 0  - очищается, усанавливается фон.
 
  
      1.13 Procedure Circle(x,y,r,mode:integer);
      
       Способ использования:

			Circle(x,y,r,mode);

       Процедура рисует окружность с центром x,y и радиусом r. Следует помнить
 что в режиме 1 радиус есть колиыество пикселов по верикали, а по горизонтали 
 окружность автоматически растягивается в 2 раза.

	mode = 1    окружность рисуется;
	mode = 0    окружность стирается.



       1.14 Procedure CirclFull(x,y,r,mode: integer); 

	Способ использования:

			CircleFull(x,y,r,mode);

	Если mode = 1 , то процедура рисует заполненную текущим цветом
   окружность. Если mode = 0 , то происходит очистка внутри окружности.

	1.15. Procedure HorizLine(x1,x2,yLine,mode: integer);

	Способ использования:

			HorizLine(x1,x2,yLine,mode);

	Это скоростная процедура рисования горизонтальной линии.
   x1 всегда < x2 . В этой процедуре нет защиты от дурака, так что 
   будте внимательны.

	mode имеет тот же смысл, что и в процедуре 1.14.	


	1.16. procedure VerticalLine(xLine, y1, y2, mode: integer);

	Способ применения:

		VerticalLine(xLine, y1, y2, mode );

	Процедура рисует вертикальную линию. Смысл mode тот же, что в 1.14.

	program example;
	var x : integer;
	procedure VerticalLine(xLine, y1, y2, mode: integer); 	external;
	procedure CurOn;					external;
	procedure CurOff;					external;
	begin
	   CurOff;    { погасить курсор }
	   for x := 0 to 319 do 
	      VerticalLine(x,0,199,1);
	   for x := 0 to 319 do 
	      VerticalLine(x,0,199,0);
	   CurOn;    { высветить курсор }
	end.


	1.17. procedure TriAngle(x1,y1,x2,y2,x3,y3,mode:integer);
					- рисование треугольника.

	Способ применения:

		TriAngle(x1,y1,x2,y2,x3,y3,mode);

	Процедура рисует(mode = 1) или стирает(mode=0) треугольник
	с координатами вершин x1,y1,x2,y2,x3,y3. Защита от дурака есть.


	1.18. procedure FullTriAngle(x1,y1,x2,y2,x3,y3,mode:integer);
					- заполненный треугольник.

	Способ применения:

		FullTriAngle(x1,y1,x2,y2,x3,y3,mode);
	
	Процедура рисует заполненный треугольник, или очищает площадь,
	им ограниченную(mode=0).

	2.1 procedure CpyScr(x,y,adr,len:integer); копирование цепочки
							байт в экран.
	Способ использования:

			CpyScr(x,y,adr,len);	

	Процедура копирует цепочку байт длины len, расположенную в памяти
	по адресу adr, в экран, начиная с x,y( графические ).

	Как определить адрес, ясно из примера:

	type
		vektor	= array [1..16] of char;
	
		pt = ^ rt;
		rt = record
			uk : pt;
			data : vektor; 
		     end;
	var
	 	i	: integer;
		str	: pt;
		adrs	: integer;	{адрес начала цепочки }
			
	procedure CpyScr(x,y,adr,len:integer);		external;
	begin
		new(str);
		{ найдем в памяти свободное место }
		str^.data:='ABABABABABABABAB';
		{ поместим туда массив- изображение}
		{$C
		MOV	str(R5),adrs(R5)
		}
		CpyScr(100,100,adrs,16);
	end.

	3. РАБОТА С ТЕКСТОМ.
	
	   Некоторые процедуры для работы с текстом используют
	подпрограммы ПЗУ версии 3( то ПЗУ, где есть псевдографика)
	-CurOn
	-CurOff
	-InvOn
	-InvOn


	3.1. 	procedure ClrScr; очистить экран

	Способ применения:

			ClrScr;

	Эта процедура очищает экран и помещает курсор в левый
	верхний угол экрана.
	

	3.2.	procedure CurOff;  погасить курсор

	Способ применения:

			CurOff;

	Курсор будет погашен, пока не встретится CurOn


	3.3 procedure CurOn;   включить курсор.

	Способ использования

			CurOn;


	3.4 procedure InvOn;   включить инверсию.

	Способ применения:

			InvOn;
		
	Весь текст после той процедуры будет напечатан с инверсией.

                                  - 9 -	
	
	3.5 procedure InvOff;  выключить инверсию.

	Способ применения:

			InvOff;

	Восстанавливается нормальный режим печати текста.



	3.6 procedure GotoXY(x, y: integer); 

	Способ применения:

			GotoXY(x, y);

	Курсор помещается в знакоместо с координатами X, Y.



	3.7. 	procedure KbMode(mode:integer); установка режимов
	клавиатуры.

	Способ использования:

			KbMode(mode);

	Процедура устанавливает следующие режимы:
		mode = 0 	нормальный режим;
		mode = 1	режим посимвольной активации с ожиданием
		mode = 2	режим посимвольной активации без ожидания
						нажатия клавиши.
	

	3.8. function  Inkey:integer;  получить код клавиши.

	Способ применения:

			i := Inkey;
 	
	Функция возвращает значение кода нажатой клавиши.
		
	пример - задержка до нажатия любой клавиши:
	....
	....
	KbMode(1);
	repeat until inkey<>0;
	KbMode(0);
	....
