## АННОТАЦИЯ

ГЕНЕРАТОР ЗАДАЧ РЕЛЯЦИОННОЙ СИСТЕМЫ УПРАВЛЕНИЯ БАЗАМИ ДАННЫХ НА МИКРО-ЭВМ (СУБД РДВ-МИКРО) ОБЕСПЕЧИВАЕТ РАБОТУ ДВУХ БАЗ ДАННЫХ С ПОМОЩЬЮ СПЕЦИАЛЬНОГО КОМАНДНОГО ФАЙЛА ЗАДАВАЕМОГО ПОЛЬЗОВАТЕЛЕМ.

НАЛИЧИЕ ПРОСТЫХ КОМАНД ПО МАНИПУЛИРОВАНИЮ ДАННЫМИ ОБЕСПЕЧИВАЕТ НАКОПЛЕНИЕ РЕЗУЛЬТАТОВ ВЫЧИСЛЕНИЯ НАД ДАННЫМИ ОДНОЙ БАЗЫ ДАННЫХ И ЗАПИСЬ ИХ В ДРУГУЮ БАЗУ.

ГЕНЕРАТОР ЗАДАЧ ПРЕДНАЗНАЧЕН ДЛЯ РЕШЕНИЯ ИТОГОВЫХ ЗАДАЧ, БАЗИРУЮЩИХСЯ НА ИСПОЛЬЗОВАНИИ МИКРО-ЭВМ.

# НАЗНАЧЕНИЕ И УСЛОВИЕ ПРИМЕНЕНИЯ

ГЕНЕРАТОР ЗАДАЧ ЯВЛЯЕТСЯ СОСТАВНОЙ ЧАСТЬЮ СУБД РБД-МИКРО (СМ.[1]), ПРЕДНАЗНАЧЕННЫЙ ДЛЯ УПРАВЛЕНИЯ РЕЛЯЦИОННЫМИ БАЗАМИ ДАННЫХ НА МИКРО-ЭВМ ТИПА "ЭЛЕКТРОНИКА-60","ЭЛЕКТРОНИКА НЦ 80-20" ИЛИ МИНИ-ЭВМ ТИПА СМ 4 ОПЕРАЦИОННОЙ СИСТЕМЕ РАФОС (ФОДОС, ОС ДВК). В КАЧЕСТВЕ ВНЕШНЕЙ ПАМЯТИ ДЛЯ ХРАНЕНИЯ ДАННЫХ ИСПОЛЬЗУЕТСЯ МАГНИТНЫЕ ДИСКИ (ГМД) ИЛИ ДРУГИЕ С КАТАЛОГОВОЙ СТРУКТУРОЙ.

ГЕНЕРАТОР ЗАДАЧ ОБЕСПЕЧИВАЕТ ОБРАБОТКУ ДАННЫХ, СОДЕРЖАНИЕ КОТОРОЙ ОПРЕДЕЛЯЕТСЯ СПЕЦИАЛЬНЫМ КОМАНДНЫМ ФАЙЛОМ, УКАЗЫВАЕМЫМ ПОЛЬЗОВАТЕЛЕМ. ДЛЯ ПОДГОТОВКИ КОМАНДНЫХ ФАЙЛОВ МОЖЕТ ИСПОЛЬЗОВАТЬСЯ ОБЫЧНЫЙ ТЕКСТОВЫЙ РЕДАКТОР.

ГЕНЕРАТОР ЗАДАЧ ОБРАБАТЫВАЕТ ДВЕ БАЗЫ ДАННЫХ. ОДНА ИЗ БАЗ ДАННЫХ ЯВЛЯЕТСЯ ИСХОДНОЙ, ДРУГАЯ РЕЗУЛЬТИРУЮЩЕЙ. НАД ДАННЫМИ ИСХОДНОЙ БАЗЫ ПРОИЗВОДЯТСЯ РАЗЛИЧНЫЕ ВЫЧИСЛЕНИЯ, ЗАДАВАЕМЫЕ ПОЛЬЗОВАТЕЛЕМ В ТЕКСТЕ КОМАНДНОГО ФАЙЛА. РЕЗУЛЬТАТЫ ВЫЧИСЛЕНИЙ НАД ДАННЫМИ ИСХОДНОЙ БАЗЫ ЗАПИСЫВАЮТСЯ В РЕЗУЛЬТИРУЮЩУЮ БАЗУ ДАННЫХ. ГЕНЕРАТОР ЗАДАЧ ПОЗВОЛЯЕТ ПРОВОДИТЬ ВЫЧИСЛЕНИЯ ПО ЗАРАНЕЕ ЗАДАННЫМ УСЛОВИЯМ.

# ОБРАЩЕНИЕ К ПРОГРАММЕ

ВЫЗОВ ГЕНЕРАТОРА ЗАДАЧ С СИСТЕМНОЙ ДИСКЕТЫ ОСУЩЕСТВЛЯЕТСЯ КОМАНДОЙ:

```
.R GENRDB
```

ГЕНЕРАТОР ЗАПРАШИВАЕТ ИМЯ КОМАНДНОГО ФАЙЛА:

```
ИМЯ ФАЙЛА? <ИМЯ ФАЙЛА>
```

ГДЕ <ИМЯ ФАЙЛА> - ВВОДИМОЕ С КЛАВИАТУРЫ ИМЯ КОМАНДНОГО ФАЙЛА. ЕСЛИ РАСШИРЕНИЕ НЕ УКАЗЫВАЕТСЯ, ТО ПО УМОЛЧАНИЮ ИСПОЛЬЗУЕТСЯ РАСШИРЕНИЕ 'CMD'.

ЕСЛИ УКАЗАННЫЙ ФАЙЛ НА УСТРОЙСТВЕ НЕ НАЙДЕН, НА ТЕРМИНАЛ ВЫДАЕТСЯ СООБЩЕНИЕ:

```
ФАЙЛ НЕ НАЙДЕН
```

ГЕНЕРАТОР ЗАДАЧ МОЖЕТ ЗАПУСКАТЬСЯ С ПОМОЩЬЮ СИСТЕМЫ МЕНЮ [2] И С ПОМОЩЬЮ КОМАНДНОГО ФАЙЛА ОПЕРАЦИОННОЙ СИСТЕМЫ. В ЭТОМ СЛУЧАЕ ИМЯ КОМАНДНОГО ФАЙЛА ДЛЯ ГЕНЕРАТОРА УКАЗЫВАЕТСЯ В СТРОКЕ, СЛЕДУЮЩЕЙ ЗА КОМАНДОЙ ВЫЗОВА ГЕНЕРАТОРА.

ПРИМЕР:

```
R GENRDB
дХ1:NAME
```

# ХАРАКТЕРИСТИКА ПРОГРАММЫ

ГЕНЕРАТОР ЗАДАЧ ВЫПОЛНЯЕТ ДЕЙСТВИЯ ПО ОБРАБОТКЕ ДАННЫХ, КОТОРЫЕ ОПРЕДЕЛЯЮТСЯ СОДЕРЖАНИЕМ ЗАРАНЕЕ ЗАГОТОВЛЕННОГО СПЕЦИАЛЬНОГО КОМАНДНОГО ФАЙЛА. КОМАНДНЫЙ ФАЙЛ ПРЕДСТАВЛЯЕТ СОБОЙ ПОСЛЕДОВАТЕЛЬНОСТЬ КОМАНД. КАЖДАЯ КОМАНДА СОСТОИТ ИЗ ИМЕНИ КОМАНДЫ И СПИСКА ПАРАМЕТРОВ.

ПРИМЕР:

```
ИБ KADRY;
УС ОТДЕЛ=155;
```

ИМЯ КОМАНДЫ ИДЕНТИФИЦИРУЕТ КОМАНДУ И ОПРЕДЕЛЯЕТ ДЕЙСТВИЕ, КОТОРОЕ ВЫПОЛНЯЕТ КОМАНДА. ПАРАМЕТРЫ КОНКРЕТИЗИРУЮТ ДЕЙСТВИЕ ВЫПОЛНЯЕМОЕ КОМАНДОЙ.

ПАРАМЕТРЫ МОГУТ ЗАДАВАТЬ:

```
ИМЯ БАЗЫ ДАННЫХ;
ПАРОЛЬ БАЗЫ ДАННЫХ;
ЛОГИЧЕСКОЕ ВЫРАЖЕНИЕ;
КЛЮЧЕВОЕ СЛОВО И Т.Д.
```

ИМЯ КОМАНДЫ ДОЛЖНО БЫТЬ ПЕРВЫМ В КОМАНДЕ. ПАРАМЕТРЫ СЛЕДУЮТ ДРУГ ЗА ДРУГОМ В СТРОГОМ ПОРЯДКЕ, ОТДЕЛЯЮТСЯ ОТ ИМЕНИ КОМАНДЫ ПРОБЕЛОМ И ДРУГ ОТ ДРУГА ЗАПЯТОЙ. ПРИЗНАКОМ КОНЦА КОМАНДЫ ЯВЛЯЕТСЯ ТОЧКА С ЗАПЯТОЙ.

# СООБЩЕНИЯ

ЕСЛИ В КОМАНДЕ КОМАНДНОГО ФАЙЛА ДОПУЩЕНА ОШИБКА, ГЕНЕРАТОР ВЫДАЕТ СООБЩЕНИЕ ОБ ОШИБКЕ С УКАЗАНИЕМ ХАРАКТЕРА И МЕСТА ОШИБКИ.

ПРИМЕР:

```

    $

***БАЗА ДАННЫХ НЕ НАЙДЕНА
```

# КОМАНДЫ ГЕНЕРАТОРА ЗАДАЧ

В ПОСЛЕДУЮЩИХ РАЗДЕЛАХ ПРИ ОПИСАНИИ ФОРМАТОВ КОМАНД ДЛЯ ВЫДЕЛЕНИЯ НЕОБЯЗАТЕЛЬНЫХ КОНСТРУКЦИЙ ИСПОЛЬЗУЮТСЯ КВАДРАТНЫЕ СКОБКИ [...].

## КОМАНДА ОТКРЫТИЯ ИСХОДНОЙ БАЗЫ ДАННЫХ

```
ИБ <ИМЯ БАЗЫ ДАННЫХ>[,<ПАРОЛЬ>];
```

ДАННАЯ КОМАНДА ОТКРЫВАЕТ ИСХОДНУЮ БАЗУ ДАННЫХ С УКАЗАННЫМ ИМЕНЕМ. В КОМАНДНОМ ФАЙЛЕ ЭТА КОМАНДА ДОЛЖНА ПРЕДШЕСТВОВАТЬ ВСЕМ ДРУГИМ КОМАНДАМ.

ЕСЛИ БАЗА ДАННЫХ ЗАЩИЩЕНА ПАРОЛЕМ, ТО ОН МОЖЕТ БЫТЬ УКАЗАН НЕПОСРЕДСТВЕННО В КОМАНДЕ. ЕСЛИ ПАРОЛЬ В КОМАНДЕ НЕ УКАЗАН, ОН ЗАПРАШИВАЕТСЯ В ДИАЛОГЕ.

ПРИМЕР:

```
ИБ KADRY,Х115;
```

ГДЕ KADRY - ИМЯ БАЗЫ ДАННЫХ, Х115 - ПАРОЛЬ.

## КОМАНДА ОТКРЫТИЯ РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ

```
РБ <ИМЯ БАЗЫ ДАННЫХ>[,<ПАРОЛЬ>];
```

ДАННАЯ КОМАНДА ОТКРЫВАЕТ РЕЗУЛЬТИРУЮЩУЮ БАЗУ ДАННЫХ С УКАЗАННЫМ ИМЕНЕМ. В КОМАНДНОМ ФАЙЛЕ ЭТА КОМАНДА ДОЛЖНА СЛЕДОВАТЬ ЗА КОМАНДОЙ "ИБ".

ЕСЛИ РЕЗУЛЬТИРУЮЩАЯ БАЗА ДАННЫХ ЗАЩИЩЕНА ПАРОЛЕМ, ТО ОН МОЖЕТ БЫТЬ УКАЗАН НЕПОСРЕДСТВЕННО В КОМАНДЕ. ЕСЛИ ПАРОЛЬ В КОМАНДЕ НЕ УКАЗАН, ОН ЗАПРАШИВАЕТСЯ В ДИАЛОГЕ.

ПРИМЕР:

```
РБ REZ,Х20;
```

ГДЕ REZ - ИМЯ БАЗЫ ДАННЫХ, Х20 - ПАРОЛЬ.

> РЕЗУЛЬТИРУЮЩАЯ БАЗА ДАННЫХ ДОЛЖНА БЫТЬ ПРЕДВАРИТЕЛЬНО СОЗДАНА.

## КОМАНДА ОПИСАНИЯ КЛЮЧЕВОГО СТОЛБЦА В ИСХОДНОЙ БАЗе ДАННЫХ.

```
     КС #<НОМЕР СТОЛБЦА>;
     КС #<НОМЕР СТОЛБЦА>,#<НОМЕР СТОЛБЦА>;
ИЛИ
     КС !<НОМЕР СТОЛБЦА>;
```

ВОЗМОЖНЫ ТРИ ВАРИАНТА ЭТОЙ КОМАНДЫ.

ПРИМЕР:

```
КС #5;
```

ГДЕ КЛЮЧЕВЫМ ЯВЛЯЕТСЯ СТОЛБЕЦ С НОМЕРОМ 5.

```
КС #5,#6;
```

ГДЕ КЛЮЧЕВЫМ ЯВЛЯЮТСЯ СТОЛБЦЫ 5,6.

```
КС !4;
```

ГДЕ КЛЮЧЕВЫМ ЯВЛЯЕТСЯ ПОДСТРОКА ЗНАЧЕНИЯ СТОЛБЦА СИМВОЛЬНОГО ТИПА, ВЫДЕЛЕННАЯ РАЗДЕЛИТЕЛЕМ ЗАПЯТАЯ ','.

В КАЧЕСТВЕ КЛЮЧЕВОГО СТОЛБЦА ВСЕГДА ЗАДАЕТСЯ ТОТ СТОЛБЕЦ ИСХОДНОЙ БАЗЫ ДАННЫХ, КОТОРЫЙ ОДНОЗНАЧНО ИМЕНУЕТ ЗАПИСЬ РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ. В РЕЗУЛЬТИРУЮЩЕЙ БАЗЕ ДАННЫХ БУДЕТ СТОЛЬКО ЗАПИСЕЙ, СКОЛЬКО НЕПОВТОРЯЮЩИХСЯ ЗНАЧЕНИЙ В КЛЮЧЕВОМ СТОЛБЦЕ ИСХОДНОЙ БАЗЫ ДАННЫХ. ДАННЫЕ ИЗ КЛЮЧЕВОГО СТОЛБЦА ИСХОДНОЙ БАЗЫ ДАННЫХ, ВСЕГДА ЗАПИСЫВАЮТСЯ В ПЕРВЫЙ СТОЛБЕЦ РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ.

РАБОТА С ДВУМЯ КЛЮЧЕВЫМИ СТОЛБЦАМИ АНАЛОГИЧНА РАБОТЕ С ОДНИМ КЛЮЧЕВЫМ СТОЛБЦОМ.

ПРИМЕР:

РЕЗУЛЬТИРУЮЩАЯ БАЗА ДАННЫХ ДЛЯ ДВУХ КЛЮЧЕВЫХ СТОЛБЦОВ

```
_____________________
!ФАМИЛИЯ !ИМЯ  ! ...!
---------------------
!ИВАНОВ  !ИВАН !    !
---------------------
!ИВАНОВ  !ПЕТР !    !
---------------------
!СИДОРОВ !ИВАН !    !
---------------------
```

> 1. КЛЮЧЕВОЙ СТОЛБЕЦ (СТОЛБЦЫ) ИСХОДНОЙ БАЗЫ ДАННЫХ ДОЛЖНЫ СООТВЕТСТВОВАТЬ ПО ТИПУ ПЕРВОМУ (И ВТОРОМУ) СТОЛБЦУ РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ.

> 2. КОМАНДА ОПИСАНИЯ КЛЮЧЕВЫХ СТОЛБЦОВ ДОЛЖНА ЗАПИСЫВАТЬСЯ В КОМАНДНОМ ФАЙЛЕ ТОЛЬКО ПОСЛЕ КОМАНД ИБ И РБ И ТОЛЬКО ОДИН РАЗ.

## КОМАНДА ОПРЕДЕЛЕНИЯ ФОРМАЛЬНОГО ПАРАМЕТРА

```
ФП <НОМЕР ПАРАМЕТРА> = <ЗАПРОС НА ВВОД ЗНАЧЕНИЯ>;
```

ГДЕ <НОМЕР ПАРАМЕТРА> - ЦЕЛОЕ ЧИСЛО, <ЗАПРОС НА ВВОД ЗНАЧЕНИЯ> - ПОСЛЕДОВАТЕЛЬНОСТЬ СИМВОЛОВ.

```
ПРИМЕР:

      ФП 1 = ВВЕДИТЕ ДАТУ;
      ФП 2 = ВВЕДИТЕ НОМЕР ОТДЕЛА;
```

КОМАНДА ИДЕНТИФИЦИРУЕТ ФОРМАЛЬНЫЙ ПАРАМЕТР И ОСУЩЕСТВЛЯЕТ ПРИВЯЗКУ ЗАПРОСА НА ВВОД ЗНАЧЕНИЯ ДЛЯ ЭТОГО ПАРАМЕТРА.

```
СИНТАКСИС ФОРМАЛЬНОГО ПАРАМЕТРА

    & <НОМЕР ПАРАМЕТРА>
```

ФОРМАЛЬНЫЙ ПАРАМЕТР МОЖЕТ ВСТЕЧАТЬСЯ В ЛЮБОМ МЕСТЕ КОМАНД ЗАДАНИЯ УСЛОВИЯ И ПОИСКА ЗАПИСИ ДАННЫХ В БАЗЕ ДАННЫХ.

```
        ПРИМЕР:

             УС (#4='&1')И(#3=&2)

ГДЕ &1 И &2 - ФОРМАЛЬНЫЕ ПАРАМЕТРЫ.
```

КАК ТОЛЬКО ГЕНЕРАТОР ЗАДАЧ ЧИТАЕТ ФОРМАЛЬНЫЙ ПАРАМЕТР &1 ИЛИ &2 НА ДИСПЛЕЙ ВЫДАЕТСЯ ЗАПРОС:

```
ВВЕДИТЕ ДАТУ
```

ИЛИ

```
ВВЕДИТЕ НОМЕР ОТДЕЛА
```

ПОЛЬЗОВАТЕЛЮ НЕОБХОДИМО ВВЕСТИ ЗАПРАШИВАЕМЫЕ ДАННЫЕ С НАЖАТИЕМ КЛАВИШИ <ВК>.

> ГЕНЕРАТОР ЗАДАЧ РАЗРЕШАЕТ ОПРЕДЕЛЕНИЕ 15 ФОРМАЛЬНЫХ ПАРАМЕТРОВ.

## КОМАНДА УСЛОВИЯ ПОИСКА

```
УС <ЛОГИЧЕСКОЕ ВЫРАЖЕНИЕ>;
```

ИЛИ

```
УС ;
```

КОМАНДА УСЛОВИЯ ДОЛЖНА ПРИСУТСТВОВАТЬ ВСЕГДА В КОМАНДНОМ ФАЙЛЕ И ЗАПИСЫВАТЬСЯ ПОСЛЕ КОМАНД УБ, РБ.

ДАННАЯ КОМАНДА ПРЕДНАЗНАЧЕНА ДЛЯ ЗАДАНИЯ УСЛОВИЯ ПОИСКА ЗАПИСЕЙ В ИСХОДНОЙ БАЗЕ ДАННЫХ. ЗАПИСИ, УДОВЛЕТВОРЯЮЩИЕ УСЛОВИЮ, ЯВЛЯЮТСЯ АКТИВНЫМИ.

ЛОГИЧЕСКОЕ ВЫРАЖЕНИЕ ЗАДАЕТСЯ В ТРАДИЦИОННОЙ ПРИОРИТЕТНОЙ ФОРМЕ ЗАПИСИ.

В ЛОГИЧЕСКОМ ВЫРАЖЕНИИ ДОПУСКАЮТСЯ:

```
АРИФМЕТИЧЕСКИЕ ОПЕРАЦИИ - '+','-','*','/';

ОПЕРАЦИИ ОТНОШЕНИЯ - '>','<','>=','<=','=','<>';

ЛОГИЧЕСКИЕ ОПЕРАЦИИ - 'И', 'ИЛИ', 'НЕ';

ОПЕРАЦИЯ СРАВНЕНИЯ СТРОКИ СИМВОЛОВ, ЗАДАВАЕМОЙ ВТОРЫМ
ОПЕРАНДОМ С ПРОИЗВОЛЬНОЙ ПОДСТРОЙКОЙ ПЕРВОГО ОПЕРАНДА -
'$';
```

ВТОРОЙ ОПЕРАНД НЕОБХОДИМО ВЫДЕЛЯТЬ КАВЫЧКАМИ ' '.

ПРИМЕР:

```
#7$'АВС', ФАМИЛИЯ$'НН'
```

ОПЕРАНДАМИ ЛОГИЧЕСКОГО ВЫРАЖЕНИЯ ЯВЛЯЮТСЯ:

```
ЦЕЛЫЕ И ВЕЩЕСТВЕННЫЕ ЧИСЛА;
```

ПРИМЕР:

```
1,7,17,3.14

ЛИТЕРАЛЫ;
```

ПРИМЕР:

```
      'КИЕВ','ИВАНОВ'

СТОЛБЦЫ БАЗЫ ДАННЫХ, ЗАДАВАЕМЫЕ СВОИМ НОМЕРОМ ИЛИ
ИМЕНЕМ;
```

ПРИМЕР:

```
#1, #2, ФАМИЛИЯ, ОКЛАД
```

ГДЕ # -СИМВОЛ-ПРИЗНАК НОМЕРА СТОЛБЦА.

ПРИМЕР КОМАНДЫ УСЛОВИЯ:

```
УС (ПОЛ='М')И(ОКЛАД>=200)ИЛИ(ПОЛ='Ж')И(ОКЛАД<=150)
```

ПРИ ЗАДАНИИ УСЛОВИЯ НЕОБХОДИМО СОБЛЮДАТЬ СООТВЕТСТВИЕ ОПЕРАЦИЙ И ТИПОВ ОПЕРАНДОВ.

АРИФМЕТИЧЕСКИЕ ОПЕРАЦИИ ИСПОЛЬЗУЮТСЯ ДЛЯ ЦЕЛЫХ И ВЕЩЕСТВЕННЫХ ЧИСЕЛ И СТОЛБЦОВ ЧИСЛОВОГО ТИПА.

ПРИ ИСПОЛЬЗОВАНИИ ОПЕРАЦИЙ ОТНОШЕНИЯ ОПЕРАНДЫ ДОЛЖНЫ СООТВЕТСТВОВАТЬ ПО ТИПУ.

ЛОГИЧЕСКИЕ ОПЕРАЦИИ ОТДЕЛЯЮТСЯ ОТ ОПЕРАНДОВ КРУГЛЫМИ СКОБКАМИ. ОПЕРАНДАМИ ДЛЯ ЛОГИЧЕСКИХ ОПЕРАЦИЙ СЛУЖАТ ОТНОШЕНИЯ.

ЕСЛИ КОМАНДА УСЛОВИЯ ЗАПИСАНА В ФОРМАТЕ УС ;, ТО ВСЕ ЗАПИСИ ИСХОДНОЙ БАЗЫ ЯВЛЯЮТСЯ АКТИВНЫМИ.

## КОМАНДА ЗАПИСИ ДАННЫХ В РЕЗУЛЬТИРУЮЩУЮ БАЗУ ДАННЫХ

ЗП #<НОМЕР СТОЛБЦА> = <ФУНКЦИЯ>;

ИЛИ

ЗП #<НОМЕР СТОЛБЦА> = <АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ>;

ДАННАЯ КОМАНДА ЗАПИСЫВАЕТ В СТОЛБЕЦ РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ ЗАПИСАННЫЙ СЛЕВА ОТ ЗНАКА РАВНО ЗНАЧЕНИЕ ФУНКЦИИ ИЛИ ВЫРАЖЕНИЯ, ПОЛУЧЕННОЕ ПРИ ОБРАБОТКЕ ДАННЫХ ИСХОДНОЙ БАЗЫ.

В КОМАНДЕ МОЖНО ИПОЛЬЗОВАТЬ ФУНКЦИИ

```
СУМ - ФУНКЦИЯ СУММИРОВАНИЯ;

ЧАЗ - ФУНКЦИЯ ОПРЕДЕЛЕНИЯ ЧИСЛА ЗАПИСЕЙ,
      УДОВЛЕТВОРЯЮЩИХ УСЛОВИЮ ПОИСКА;

МИН - ФУНКЦИЯ ОПРЕДЕЛЕНИЯ НАИМЕНЬШЕГО;

МАХ - ФУНКЦИЯ ОПРЕДЕЛЕНИЯ НАИБОЛЬШЕГО;
```

> АРГУМЕНТОМ ФУНКЦИИ СУМ ЯВЛЯЕТСЯ ТОЛЬКО НОМЕР ЧИСЛОВОГО СТОЛБЦА ИСХОДНОЙ БАЗЫ ДАННЫХ. АРГУМЕНТОМ ФУНКЦИЙ МИН, МАК, ЯВЛЯЮТСЯ НОМЕРА ЧИСЛОВОГО И СИМВОЛЬНОГО СТОЛБЦА.

ПРИМЕР:

```
        ЗП #3=СУМ(#6)

ГДЕ 3   - НОМЕР СТОЛБЦА РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ,
    А 6 - НОМЕР СТОЛБЦА ИСХОДНОЙ БАЗЫ ДАННЫХ.
```

В КОМАНДЕ МОЖНО ИСПОЛЬЗОВАТЬ АРИФМЕТИЧЕСКОЕ ВЫРАЖЕНИЕ НЕ СОДЕРЖАЩЕЕ ФУНКЦИЙ

ПРИМЕР:

```
        ЗП #4=#5/3

ГДЕ 4 - НОМЕР СТОЛБЦА РЕЗУЛЬТИРУЮЩЕЙ БАЗЫ ДАННЫХ;
    5 - НОМЕР СТОЛБЦА ИСХОДНОЙ БАЗЫ ДАННЫХ;
```

> КОМАНДА ЗП ВСЕГДА ДОЛЖНА СЛЕДОВАТЬ ЗА КОМАНДОЙ УС;

ПРИМЕР РАБОТЫ ГЕНЕРАТОРА ЗАДАЧ

```
     ИСХОДНАЯ БД ОДТ:
_________________________
!ОТДЕЛ !СЕКТОР !ЗАРПЛАТА!
-------------------------
!НТО-1 ! 1     !1000    !
-------------------------
!НТО-2 ! 2     !500     !
-------------------------
!НТО-1 ! 1     !700     !
-------------------------
!НТО-3 ! 3     !800     !
-------------------------
```

РЕЗУЛЬТИРУЮЩАЯ БД SUM

```
_________________________
!   ОТДЕЛ   !  ИТОГ     !
!           !           !
-------------------------
```

КОМАНДНЫЙ ФАЙЛ СУММИРОВАНИЯ ЗАРПЛАТЫ ПО ОТДЕЛАМ ПРИМЕТ ВИД:

```
ИБ ОдТ;
РБ SUM;
КС #1;
УС;

ЗП #2=СУМ (#3);
```

```
   РЕЗУЛЬТИРУЮЩАЯ БД SUM
--------------------------

--------------------------
! НТО-1     ! 1700       !
--------------------------
! НТО-2     !  500       !
--------------------------
! НТО-3     !  800       !
--------------------------
```

> ПРИ ОПИСАНИИ ИСХОДНОЦ И РЕЗУЛЬТИРУЮЩИХ БАЗЫ ДАННЫХ ПОЛЬЗОВАТЬСЯ СТОЛБЦАМИ С ТИПОМ 3 (СИМВОЛЬНАЯ СТРОКА ПЕРЕМЕННОЙ ДЛИННЫ) НАДО ТОЛЬКО В КРАЙНЕМ СЛУЧАЕ.
