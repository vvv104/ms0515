# OUT17

```
1.Утилита OUT17 предназнаяена для вывода текстовых файлов
  на струйный принтер МС6317, подключенный к параллельному порту
  мс0515.

2.Как пользоваться программой. Пусть надо напечатать текст 'P.TXT'.
   - подать команду
        .OUT17 P.TXT <вк>
   - включить принтер;
   - нажать клавишу 'пробел'
   - текст будет напечатан.

3.Возможно использование ключей.

3.1 Ключ L для вывода текста с остановкой после печати 1 страницы.
    Пусть надо печатать текст 'NAM.LST', по 40 (десятич.) строк в
    странице.

        .OUT17 NAM.LST/L:40. <вк>

3.2 Ключ H нужен для выбора шрифта (Esc ! n). Пусть надо печатать
    текст 'A.DOC' сжатым шрифтом. Подать команду

        .OUT17 A.DOC/H:5

3.3 Ключ V задает межстрочное расстояние (0 < n < 256.)

        .OUT17 A.DOC/V:40.


                        ~~~~~~~~~

Подробнее :: Домнич А.В. тел. в Каменке 8 - 257 - 5 - 18 - 21
```
