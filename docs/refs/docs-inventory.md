## Легенда (из исходного XLS)

Цветовое кодирование в оригинале:

- *"Х.ХХХ.ХХХ ХХ"* — Есть в бумажном виде
- *"Х.ХХХ.ХХХ ХХ"* — Нет в бумажном виде
- *"Х.ХХХ.ХХХ ХХ"* — Есть в отсканированном виде (гиперссылка → `www.tis.kz`)
- *"Х.ХХХ.ХХХ ХХ"* — Есть в отсканированном виде (гиперссылка → `www.tis.kz`)

> Примечание автора каталога: *«Если имеется отсканированный вариант, это
> ещё не значит, что это скан именно этого бумажного документа.»*

## Что приоритизировать для OCR следующим

В порядке убывания полезности для нашего проекта эмуляции:

1. **`mc0515-osa.rar`** (21 МБ) — официальная документация на ОС ОСА.
   Расшифрует драйверы VS/VM/DZ детально, объяснит формат файла, опишет
   все системные вызовы. Поможет в реализации эмулируемой ОС в тестах.

2. **`mc0515-to.rar`** (37 МБ) — техническое описание машины. Содержит
   карту памяти, регистры устройств, временные диаграммы — чистое
   золото для эмулятора железа.

3. **`hc4-to.rar`** (42 МБ) — техническое описание системного модуля НС4
   (это и есть основная плата МС-0515). Схема, перечень элементов,
   распиновка.

4. **`mc0515-ed.rar`** (39 МБ) — ведомость эксплуатационных
   документов: справочный документ, который должен ссылаться на все
   остальные.

5. **`ngmd-nmd.rar`** (2 МБ) — описание НГМД (флоппи). Может объяснить
   формат секторов, interleave-формулу, поведение FDC.

6. **`MC1702.rar`** — ~~видеомодуль~~ сопроцессор IBM PC на КМ1810ВМ86 (расшифрован, см. выше); к VS.SYS отношения не имеет.
