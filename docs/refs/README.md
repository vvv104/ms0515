Этот каталог содержит расшифрованные (OCR + ручной вычитка) русские
сканы оригинальной заводской документации на ПЭВМ «Электроника МС 0515»
производства завода «ПРОЦЕССОР» (г. Воронеж).

Источник сканов: каталог `scans/` в архиве пользовательских материалов
(DjVu/PDF от 2011 года, оригиналы — на сайте `www.tis.kz`).

## Ключевые открытия из этих документов

1. **Расшифровка драйверов** (приложение 1 к 0515-OSA подтверждает):
   - `DZ.SYS` — драйвер гибких дисков
   - `VS.SYS` — драйвер **синтезатора звука** (НЕ видео!)
   - `VM.SYS` — драйвер имитатора **дискового ВЗУ** (RAM-диск)
   - `TT.SYS` — драйвер терминала
   - `LP.SYS` — драйвер устройства печати
   - `NL.SYS` — драйвер фиктивного устройства
   - `SL.SYS` — редактор командной строки
   - `MON8SJ.SYS` — монитор системы
   - `SWAP.SYS` — файл свопинга

2. **Расшифровка прикладных программ** (приложение 1 к 0515-OSA):
   - `K13U.SAV` — экранный редактор текста (вариант KED/К13 для
     терминала МС0515)
   - `TFP.SAV` — программа форматирования текста (директивы
     `.LIN`/`.BLN`/`.SKI`/`.INT`/`.SWT`/`.NOF`/`.MID`/`.RIT`,
     `.BTL`/`.PAG`/`.TES`, `.TIT`/`.TOC`/`.ANN`/`.APN`/`.CPT`/
     `.HLV`/`.AND`/`.TBL`/`.ATT`/`.LST`, `.COM`/`.CHA`/`.CPY`)
   - `DUP.SAV` — программа обслуживания устройств
   - `PIP.SAV` — программа обмена
   - `DIR.SAV` — программа получения справочника
   - `RESORC.SAV` — программа информации о состоянии системы
   - `DATSET.SAV` — программа установки даты
   - `HELP.SAV` — программа справочной информации
   - `BAS.SAV` — интерпретатор языка Бейсик
   - `TERM.SAV` — программа эмуляции терминала
   - `START.COM` — стартовый командный файл

2. **Расшифровка `183107.SAV/EXE`** — это **«Упражнитель МС0515»**
   (тренировочная/exerciser-программа), главная тестовая программа из
   штатной поставки. Она циклически «упражняет» ЦП, таймер, контроллёр
   НГМД и интерфейс последовательного обмена на стресс-нагрузке.
   Тот же файл найден в архивных дискетах ARCSAV/disk4 под именем
   `183107.EXE`.

3. **Реликвия пользователя**: в формуляре указан заводской № **2.791.864**,
   завод «ПРОЦЕССОР», г. Воронеж, выпуск **октябрь 1992 г.**, исполнение
   **МС 0515.03**. Серийные номера комплектующих:
   - Монитор МС-6113М: 9070-9070
   - Клавиатура МС-7004: 445.95.043315

4. **Минимальный загрузочный набор**: `MON8SJ.SYS` + `SWAP.SYS` + `DZ.SYS`
   + `TT.SYS` — это тот же базовый комплект, что наблюдается в наших
   распаковках (например, на диске Buhgal — только эти и есть).

5. **Программная среда**: ПЭВМ обеспечивает использование ОС **ОСА**,
   совместимой с RT-11/SJ-11 (т.е. это **RT-11-совместимая** Soviet OS),
   плюс языки **АССЕМБЛЕР** и **БЕЙСИК**.

6. **Происхождение ОСА** (перечень ссылочных документов 0515-OSA,
   л. 57): в качестве источника для экранного редактора прямо
   указана ОС **Фодос-2** (`.00042-01 34 05`) — советский клон
   RT-11SJ. Это подтверждает, что ОСА — производная Фодос-2 для
   МС0515.

7. **Состав штатного дискета №1** (приложение 2 к 0515-OSA):
   20 файлов, 501 блок занято, 285 свободных. Минимальная
   работоспособная система (явно указанная в 0515-OSA, п. 2.7.3):
   `{ MON8SJ, SWAP, DZ, VM }.SYS` + `{ PIP, DUP, DIR }.SAV`.
