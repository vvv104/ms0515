Saboteur II on the MS-0515

The machine below is the emulator's page in a frame, opened at a run card: a few lines of JSON naming the game and its files, which the page starts at once - no diskette, no boot - on the machine it carries (ROM-B, DEC's RT-11). Click the arrow, then play: the keys go to the game.

The frame is one line of HTML; run= names the card and embed=1 leaves the toolbar and the card's words out. Open the same card in the full page to see what to press.

<iframe src="https://vvv104.github.io/ms0515/?run=https://vvv104.github.io/ms0515-software/play/sabot2.json&embed=1"
        width="640" height="400" allow="autoplay; fullscreen"></iframe>

The cards of the games are the software collection's (ms0515-software, play/); a card of your own goes on any server that lets this page fetch it, named in full in run=.
