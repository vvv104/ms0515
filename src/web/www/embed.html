Saboteur II on the MS-0515

The machine below is the emulator's page in a frame, opened at a start file: a snapshot taken right after R SABOT2, the diskette the game runs from, and the settings (the drive and the keyboard quiet, the speaker on). Click the arrow, then play: the keys go to the game. Reset in the full page is the same moment again.

The frame is one line of HTML; start= names the file and embed=1 leaves the toolbar out. Open the same start in the full page to see the drives and the settings behind it.

        width="640" height="400" allow="autoplay; fullscreen"></iframe>

A start file of your own: a card (the title, the disk, what to type, the sounds) and tools/make_start.py in the emulator's repository make one; put it on any server that lets this page fetch it and name it in full in start=.
