Keys

  • The machine waits behind a play arrow until you click it: a browser lets no page make a sound before it has been touched, and a machine started without one does its whole boot in silence. Come back another day and the arrow is gone - by then the browser trusts the site and the machine starts by itself.
  • Click the screen to type. RT-11 asks the date and the time at boot; Enter skips both.
  • The keyboard is the MS7004: letters, digits and symbols as on the caps (РУС mode: positional ЙЦУКЕН); arrows, the keypad, F1–F13; Home / Ins / Del / End / PgUp / PgDn are the editing keys. Left Alt = Compose, Right Alt = РУС/ЛАТ.
  • ⛶ or F11: the picture alone on the whole screen, Esc brings the page back. On a touch device ⌨ raises the system's keyboard; its Cyrillic letters switch the machine to РУС.
  • Joystick: on makes the arrows and Space the joystick on the MS7007 port (SABOT2: J KEMPSTON); on a touch screen a stick sits under a finger on the left of the picture, fire on the right.

Drives

  • A and B: a 400 KB image is one side, an 800 KB image both sides of its drive. HD takes an image of any size - your own, or a new blank one (INIT HD: in the guest).
  • An 800 KB image holding a whole-disk DV: or MZ: volume (1600 blocks, no sides) shows as DV0: / MZ0: - the content decides, not the size. An uninitialised two-sided image is one entity until an INIT names its kind; a re-INIT of another kind erases the previous one.

Files

Two panes over the mounted disks' RT-11 directories, the keys below as in Midnight Commander.

  • F1 Upload a file of yours (a 6.3 name) · F2 Download · F3 View · F4 Edit · F5 Copy to the other pane · F6 Rename · F7 Squeeze · F8 Delete · F9 Init the volume · F10 Quit.
  • Mark files with Insert or Shift+arrows; F2 / F5 / F6 / F8 take the marked ones. + / − mark or unmark by an OS pattern (*.MAC, A%B.*, several with commas); * alone inverts the marks.
  • Disks are DZ0: .. DZ3: and HD0:. F5 on one file or F6 takes a DZn:NAME: a copy under another name, a rename, or a move to another disk.
  • F9 is the OS's INITIALIZE: volume id, owner and directory size, or the id alone with the files kept; a two-sided image can become one whole-disk DV: or MZ: volume.
  • With Alt held: Alt+F1 / F2 a pane's disk list · Alt+F3 compare two files side by side, what they have in common skipped: the two marked on this pane, or one marked on each pane whatever they are named, or - nothing marked - the file under the cursor against the file of that name on the other pane. Text when both read as text, bytes when either does not; there F1 changes that, F2 hides or shows the stretches they agree on, F4 and F5 the encoding of the left and of the right file, F6 goes to the next place they differ, F7 searches through both at once - whichever comes first - F3 repeats that search without asking again, and Alt with any of the three goes the other way · Alt+F5 gather the marked files into a logical disk (a file the system mounts: MOUNT LD0: DZn:NAME.DSK) · Alt+F6 protect the marked files, or unprotect them · Alt+F7 find by pattern on every disk · Alt+F8 undelete the file an unused area was (the OS's DELETE leaves its name, length, date and data), or Recover a bare area as a file · Alt+F9 make the pane's floppy a bootable system volume of the other pane's disk: the kit copied and protected, the marked files with it, the bootstrap written as COPY/BOOT does.
  • Enter on a logical disk opens it like a directory (Backspace back out); its files are viewed, copied and deleted there, and the changes go back into the file, which grows as needed.
  • A protected file is deleted or moved only after one more Yes / No.
  • Viewer: F1 text / octal / hex · F2 wrap at 80 · F4 the encoding (ASCII, KOI-8R, KOI-7, CP866) · F5 go to a line · F7 search, F3 the same again without asking, Alt with either backwards. Editor: F2 save, F8 replace / insert.

Your data

  • Disks you write to stay in this browser (IndexedDB). Download saves a copy, Revert returns a shipped disk to its original, Delete removes one of yours.
  • The published page counts visits (GoatCounter): that a page was opened, which browser and system it was opened in, and from which country and which link. No cookie is set, nothing identifies you, and no address is stored. Nothing else about the machine you run here leaves the browser.
  • Save state keeps the machine itself - its memory and CPU as they are - so Restore brings it back after a reload, or another day. It needs the ROM it was saved with and the images it had mounted. One state is kept; saving again replaces it.

Bug report

  • The machine stopped, or stopped answering? Bug report holds it still, asks what happened and saves one file: the state, the ROM, the mounted images and the picture - enough to put the fault back on the developer's screen. Nothing is sent anywhere; the file is yours to send. The button turns red by itself once the CPU has halted.
