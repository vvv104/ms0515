## 1. Общие сведения об изделии

Сопроцессор «Электроника МС 1702» предназначен для обеспечения возможности постановки на персональном вычислительном комплексе (ПВК) «Электроника МС 0585» операционных систем, ориентированных на использование микропроцессора типа КМ1810ВМ86, с целью эксплуатации программных средств, разработанных в среде указанных систем.

## 2. Основные технические данные

| Параметр | Значение |
|----------|----------|
| Микропроцессор | КМ1810ВМ86, 16 бит |
| Время обращения к памяти, не более | 0,8 мкс |
| ОЗУ / ПЗУ | 512 / 16 Кбайт |
| Рабочая тактовая частота | 5 МГц |
| Потребляемая мощность (при 5,25 В), не более | 21 В·А |
| Ток потребления, не более | 4,0 А |
| Габариты / масса | 130×310×15 мм / 0,4 кг |
| Питание | +5 В ± 0,25 В |

Содержание драгоценных материалов (п. 2.2): золото — 3,498973 г; серебро — 1,58271 г; платина — 0,99 г; палладий — 2,0525186 г.

Встроенные средства контроля и диагностики — имеются (п. 2.4).

**Функции под управлением ПВК** (п. 2.5):
- самотестирование с выводом на экран сообщений о неисправностях;
- загрузка операционной системы **ЭЛДОС 2.0**;
- выполнение команд ОС ЭЛДОС 2.0;
- эксплуатация средств автоматизации программирования в среде ОС ЭЛДОС 2.0;
- эксплуатация прикладных программных средств в среде ОС ЭЛДОС 2.0.
